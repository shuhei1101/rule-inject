# 環境変数

設定ファイルを指す環境変数と、索引の変数参照の値

フックは、Claude Code の設定の `env` に配置した値を環境変数として受け取る。
環境変数を変えたら Claude Code を再起動する。
設定ファイルと索引の YAML の中身は、フックが呼ばれるたびに再読込するので、変えた内容は次の呼び出しから有効になる。

| 環境変数 | 配置する設定 | 内容 | 既定値 |
| --- | --- | --- | --- |
| `RULE_INJECT_CONFIG` | `~/.claude/settings.json`。サーバーを起動する側の環境にも同じ値を配置する | 設定ファイル `settings.yaml` のパス。絶対パスか `~` で始まるパス。既定と違う場所に配置するときだけ使用する | `${XDG_CONFIG_HOME:-~/.config}/rule-inject/settings.yaml`（ファイルが無ければ全てのキーを既定値で動かす） |
| `RULE_INJECT_PORT` | `~/.claude/settings.json` とサーバーを起動する側の環境 | MCP サーバーの待ち受けと、プラグインの `.mcp.json` の接続先のポート。1024〜65535 の整数 | `8783` |
| `RULE_INJECT_STATE_DIR` | `~/.claude/settings.json`。サーバーを起動する側の環境にも同じ値を配置する | 既読の記録の配置場所。`global.state_dir` より優先し、既定のログのフォルダもこの下の `logs` になる | なし（`global.state_dir`、無ければ `${XDG_STATE_HOME:-~/.local/state}/rule-inject`） |

プロジェクトの `.claude/settings.json` の `env` には配置しない。
プロジェクトごとの違いは、設定ファイルの `projects` に記載する。

設定ファイルの中身は [設定ファイル](設定ファイル.md)。

## 変数参照の値

索引の `rule` に記載した `!{名前}` は、同じ名前の環境変数の値に置き換わる（[索引の書式](索引の書式.md)）。
値は、ほかの環境変数と同じく Claude Code の設定の `env` か、Claude Code を起動する側の環境に配置する。
ルールの本文に記載した `!{名前}` の展開は、[alias-inject](https://github.com/shuhei1101/alias-inject) が担う。

常駐の MCP サーバーは、`rule` の `!{名前}` をサーバーを起動した環境の環境変数で展開する。
フックと同じ結果にするには、起動する側にも同じ名前の環境変数を配置する（[MCPツール](MCPツール.md)）。
