# MCPツール

ルールの本文を返すツール read_rules の引数と戻り値

`read_rules`（完全名 `mcp__plugin_rule-inject_rule-inject__read_rules`）は、ルールの場所か、これから触るファイルのパスを受け、当たるルールの本文を返す。
返した場所は、そのセッションの既読として記録する。
既読の履歴（`{session_id}.history.jsonl`）にも、読み方 `read_rules` で 1 行ずつ残す（[ルールの案内](../はじめに/コアコンセプト/ルールの案内.md)）。

## 引数

| 引数 | 型 | 必須 | 既定値 | 内容 |
| --- | --- | --- | --- | --- |
| `locations` | 文字列のリスト | - | `[]` | 読みたいルールの場所。案内に載った場所をそのまま渡す |
| `paths` | 文字列のリスト | - | `[]` | これから作る・変えるファイルの絶対パス。当たるルールの本文を返す。まだ無いパスも渡せる |
| `session_id` | 文字列 | ✅ | - | 呼び出し元のセッションの識別子。渡さない（フックが足す） |

- `locations` と `paths` のどちらかは渡す
- `locations` に渡せるのは、索引に載ったルールの場所（絶対パス・`~` で始まるパス・`https://` の URL）だけ
- `session_id` は 1〜128 文字の英数字・`_`・`-`

```json
{
  "locations": ["/home/user/rules/python.md"],
  "paths": ["/home/user/project/src/app.py"]
}
```

## 戻り値

| フィールド | 型 | 内容 |
| --- | --- | --- |
| `pages[].location` | 文字列 | 本文を返したルールの場所（解決後の絶対パスか URL） |
| `pages[].body` | 文字列 | ルールの本文 |
| `deferred[]` | 文字列のリスト | 応答の上限に収まらず返さなかった場所。次の呼び出しで `locations` に渡す |
| `failures[].location` | 文字列 | 本文を取得できなかった場所 |
| `failures[].reason` | 文字列 | 取得できなかった理由 |
| `history_failures[].location` | 文字列 | 既読にはしたが、既読の履歴に書けなかった場所。書けなかったときだけ応答に載る |
| `history_failures[].reason` | 文字列 | 既読の履歴に書けなかった理由（履歴ファイルの場所と OS のエラー） |

```json
{
  "pages": [{"location": "/home/user/rules/python.md", "body": "# Python の規約\n..."}],
  "deferred": [],
  "failures": [{"location": "https://example.com/rules/web.md", "reason": "HTTP 404"}]
}
```

`deferred` と `failures` の場所は既読にしない。
一部の場所を取得できなかったときも、`failures` に載せて正常に返す。
`deferred` と `failures` の場所は、既読の履歴にも残さない。
`history_failures` の場所は、本文が `pages` にあり、既読にもなっている。

## 変数参照の展開

`pages[].body` の `!{名前}`（名前は `[A-Za-z_][A-Za-z0-9_]*`）は、MCP サーバーが起動したときの同じ名前の環境変数の値に置き換えて返す。
空の値は空文字に置き換える。
設定されていない名前は `!{名前}` のまま残し、本文の先頭に次の 1 行を足す。

```text
> 注釈: 次の変数参照は、環境変数が設定されていないため展開していない: {名前}、{名前}
```

値を変えたときは、Claude Code を起動し直す。
応答の大きさは、置き換えて注釈を足した後の本文で数える。

## 制約

| 項目 | 内容 |
| --- | --- |
| 応答の大きさ | 応答全体で 40,000 字。収まらない本文は `deferred` へ回す。本文 1 件だけで超えるときは `failures` に理由を添えて返す |
| URL の取得 | `https://` の URL だけ。1 件あたり 1 秒で打ち切り、再試行しない。`http://` の URL は取得せずに `failures` に載せる |
| 読める場所 | 索引に載ったルールの場所だけ。載っていない場所は読まずに `failures` に「索引に載っていない場所」として載せる |

## エラー

| 発生条件 | 内容 |
| --- | --- |
| `session_id` が無いか形が外れている | エラーを返し、本文も返さない。フックが動いていない設定の誤り |
| `locations` と `paths` がどちらも空 | エラーを返す |
| 記録フォルダ（`RULE_INJECT_STATE_DIR`）に書けない | 記録フォルダの場所と理由を載せてエラーを返す。本文を返しても既読にならないため |
| 既読の記録には書けたが、既読の履歴に書けない | エラーにせず、本文を返して `history_failures` に場所と理由を載せる。既読にはなっているため |
