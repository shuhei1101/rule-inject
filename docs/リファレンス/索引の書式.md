# 索引の書式

ルール索引の YAML のキー

索引は利用者が書く YAML で、置き場所と名前は自由。
環境変数（[環境変数](./環境変数.md)）で指す。
フックが標準ライブラリだけで読むため、次のキーとマップ・文字列のリスト・文字列の形だけを読む。

```yaml
default_on: [read, write, mcp]
rules:
  - rule: ./python.md
    paths:
      - "**/*.py"
    exclude:
      - "**/tests/**"
    on: [write]
  - rule: https://raw.githubusercontent.com/example/rules/master/github.md
    tools:
      - "mcp__*__create_*"
  - rule: ./knowledge.md
    tools:
      - "re:__search_docs$"
    args:
      kind:
        - rule
      filter.tags:
        - "re:^python"
    read_by:
      - tools:
          - "mcp__docs__get_doc"
        args:
          id:
            - "re:^python"
```

## 索引のキー

| キー | 型 | 必須 | 既定値 | 内容 |
| --- | --- | --- | --- | --- |
| `default_on` | `read` / `write` / `mcp` のリスト | - | `[read, write, mcp]` | エントリが `on` を書かないときの、操作を止める操作の種別 |
| `rules` | エントリのリスト | - | - | ルールごとのエントリ |

## エントリのキー

| キー | 型 | 必須 | 既定値 | 内容 |
| --- | --- | --- | --- | --- |
| `rules[].rule` | 文字列 | ✅ | - | ルールの本文の場所 |
| `rules[].paths` | 文字列のリスト | - | なし（パスでは当てない） | 操作の対象の絶対パスに当てる glob か正規表現 |
| `rules[].exclude` | 文字列のリスト | - | なし（外さない） | `paths` に当たっても、このパターンに当たるパスにはそのエントリを当てない |
| `rules[].tools` | 文字列のリスト | - | なし（ツール名では当てない） | MCP のツールの完全名に当てる glob か正規表現 |
| `rules[].args` | キー → 文字列のリストのマップ | - | なし（引数では絞らない） | `tools` に当たった MCP のツールの引数に当てる glob か正規表現。書いた全てのキーの値が当たるときだけエントリを当てる |
| `rules[].on` | `read` / `write` / `mcp` のリスト | - | `default_on` | 未読のときに操作を止める操作の種別。当たった操作がここに無ければ、止めずに案内する |
| `rules[].read_by` | 要素のリスト | - | なし（MCP のツールの呼び出しでは既読にしない） | そのルールを既読にする MCP のツールの呼び出し。要素のどれか 1 つに当たった呼び出しが終わった後に、そのセッションの既読にする |
| `rules[].read_by[].tools` | 文字列のリスト | ✅ | - | 既読にする MCP のツールの完全名に当てる glob か正規表現 |
| `rules[].read_by[].args` | キー → 文字列のリストのマップ | - | なし（引数では絞らない） | 同じ要素の `tools` に当たった呼び出しの引数に当てる glob か正規表現。書いた全てのキーの値が当たるときだけ既読にする |

### rule

書けるのは次の場所。

| 場所 | 例 |
| --- | --- |
| `https://` で始まる URL | `https://raw.githubusercontent.com/example/rules/master/github.md` |
| 絶対パス | `/home/user/rules/python.md` |
| `~` で始まるパス | `~/rules/python.md` |
| 索引ファイルのフォルダからの相対パス | `./python.md` |

`http://` の URL は書けるが、本文は取得しない（平文で取得したルールを案内に使わないため）。
`rule` が無いエントリは読み飛ばし、索引が読めないときと同じく理由がコンテキストに載る。

`rule` には `!{名前}`（名前は `[A-Za-z_][A-Za-z0-9_]*`）を書ける。
同じ名前の環境変数の値に置き換えてから場所を解く（例 `!{RULES_DIR}/python.md`）。
空の値は空文字に置き換える。
設定されていない名前が残ったエントリは読み飛ばし、索引の場所・`rule`・展開できない名前がコンテキストに載る。

### paths と exclude

`**/` か `*` で始まる glob を書く。
`**` はフォルダをまたぐ。
照合は操作の対象の絶対パスに対して行う。

### tools

`mcp__` で始まる glob を書く（例 `mcp__*__create_*`）。
`paths` と `tools` は別々に照合され、書かなかった方は当たらない。
このプラグイン自身の MCP ツール（`mcp__plugin_rule-inject_rule-inject__*`）には案内しない。

### args

`tools` に当たった MCP のツールの呼び出しにだけ当てる。
キーは引数の名前で、オブジェクトの子はドットで結ぶ（例 `filter.kind`）。
タグや文書の種類を引数で受けるツールも、この書き方で当てられる。

- 書いた全てのキーについて、値がリストのどれかのパターンに当たるときだけエントリを当てる
- キーが引数に無いとき、値がオブジェクトのときは当てない
- 値が配列のとき、およびドット区切りのキーの途中が配列のときは、要素ごとに照合し、どれか 1 つが当たれば当てる
- 文字列以外のスカラーは JSON の表記（`true`・`null`・`1.5`）の文字列にして照合する

`args` は、`キー:` の下にパターンのリストを並べたブロックのマップだけを読む。
`{...}` のマップ・空の `args`・同じキーの重複は、その索引を読めなくする（索引の場所と理由がコンテキストに載る）。

### read_by

MCP のツールで文書を読む運用でも、読んだルールを既読にする。
要素のどれか 1 つに当たった呼び出しが終わった後に、そのエントリのルールをそのセッションの既読にする。
既読になったルールは、案内で操作を止めない。

- `tools` は `rules[].tools` と、`args` は `rules[].args` と同じ書き方で、引数の照合の規則も同じ
- 案内用の `tools`・`args` に当たっただけでは既読にしない
- このプラグイン自身の MCP ツール（`mcp__plugin_rule-inject_rule-inject__*`）は、書いても当たらない。`read_rules` が既読にする
- `tools` が無い要素があると、その索引を読まず、索引が読めないときと同じく索引の場所と理由がコンテキストに載る

### 正規表現

`paths`・`exclude`・`tools`・`args` のパターンは、`re:` で始めると正規表現になる。
`read_by` の `tools`・`args` のパターンも同じ。
`re:` の後ろを Python の正規表現として、対象の文字列に部分一致（`re.search`）で照合する。
全体に当てるときは `^` と `$` を書く。
`re:` で始まらないパターンは、今までどおり glob として読む。

読めない正規表現を書いたエントリは読み飛ばし、索引の場所・パターン・理由がコンテキストに載る。
同じ索引のほかのエントリは読む。

### on

| 値 | 操作 |
| --- | --- |
| `read` | Read、Grep、Bash での読み取り |
| `write` | Edit、Write、NotebookEdit |
| `mcp` | MCP のツールの呼び出し |

同じルールの場所に複数のエントリが当たったときは、案内を 1 件にまとめ、どれか 1 つでも止めるなら止める。
場所は、解決後の絶対パスか URL で同じものを同じルールとして数える。
