# 環境変数

設定ファイルを指す環境変数と、索引の変数参照の値

フックは、Claude Code の設定の `env` に置いた値を環境変数として受け取る。
環境変数を変えたら Claude Code を起動し直す。
設定ファイルと索引の YAML の中身は、フックが呼ばれるたびに読み直すので、変えた内容は次の呼び出しから効く。

| 環境変数 | 置く設定 | 内容 | 既定値 |
| --- | --- | --- | --- |
| `RULE_INJECT_CONFIG` | `~/.claude/settings.json` | 設定ファイル `settings.yaml` のパス。絶対パスか `~` で始まるパス | なし（設定ファイルを読まず、全てのキーを既定値で動かす） |

プロジェクトの `.claude/settings.json` の `env` には置かない。
プロジェクトごとの違いは、設定ファイルの `projects` に記載する。

設定ファイルの中身は [設定ファイル](./設定ファイル.md)。

## 変数参照の値

索引の `rule` に書いた `!{名前}` は、同じ名前の環境変数の値に置き換わる（[索引の書式](./索引の書式.md)）。
値は、ほかの環境変数と同じく Claude Code の設定の `env` か、Claude Code を起動する側の環境に置く。
ルールの本文に書いた `!{名前}` の展開は、[alias-inject](https://github.com/shuhei1101/alias-inject) が担う。
