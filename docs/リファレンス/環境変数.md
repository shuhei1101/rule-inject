# 環境変数

索引と既読の記録の置き場所を指す環境変数の一覧

フックと MCP サーバーは、Claude Code の設定の `env` に置いた値を環境変数として受け取る。
MCP サーバーは起動したときの値を持ち続けるため、環境変数を変えたら Claude Code を起動し直す。
索引の YAML の中身は、フックも MCP サーバーも呼ばれるたびに読み直すので、変えた内容は次の呼び出しから効く。

| 環境変数 | 置く設定 | 内容 | 既定値 |
| --- | --- | --- | --- |
| `RULE_INJECT_INDEXES_USER` | `~/.claude/settings.json` | 全プロジェクトで使う索引のパス | `${XDG_CONFIG_HOME:-~/.config}/rule-inject/rules.yaml` |
| `RULE_INJECT_INDEXES_PROJECT` | プロジェクトの `.claude/settings.json` | そのプロジェクトだけで使う索引のパス | `${CLAUDE_PROJECT_DIR}/rules.yaml` |
| `RULE_INJECT_STATE_DIR` | `~/.claude/settings.json` | セッションごとの既読の記録ファイルと既読の履歴ファイルを置くフォルダ | `${XDG_STATE_HOME:-~/.local/state}/rule-inject` |
| `RULE_INJECT_RECORD_RETENTION_DAYS` | `~/.claude/settings.json` | 既読の記録ファイルと既読の履歴ファイルを残す日数 | `30` |
| `RULE_INJECT_LOG_DIR` | `~/.claude/settings.json` | 失敗した操作を書くログのフォルダ | `${XDG_STATE_HOME:-~/.local/state}/rule-inject/logs` |
| `RULE_INJECT_LOG_RETENTION_DAYS` | `~/.claude/settings.json` | ログのファイルを残す日数 | `3` |

## 索引のパス

`RULE_INJECT_INDEXES_USER` と `RULE_INJECT_INDEXES_PROJECT` は、カンマ区切りで複数の索引を並べられる。
両方のエントリを合わせて当てる。

| 環境変数 | 書けるパス |
| --- | --- |
| `RULE_INJECT_INDEXES_USER` | 絶対パス、`~` で始まるパス |
| `RULE_INJECT_INDEXES_PROJECT` | 絶対パス、`~` で始まるパス、プロジェクトの直下（環境変数 `CLAUDE_PROJECT_DIR`）からの相対パス |

環境変数を置かないときは、既定値の置き場所の索引を読む。
既定値の置き場所にファイルが無いとき（プロジェクトの索引は `CLAUDE_PROJECT_DIR` が無いときも）は、何も知らせずに読まない。
環境変数を空の文字列にすると、既定値の置き場所も読まない。

索引の中身は [索引の書式](./索引の書式.md)。

## 既読の記録の置き場所

`RULE_INJECT_STATE_DIR` には、絶対パスか `~` で始まるパスを書く。
フォルダが無ければ書く側が作る。
記録ファイルは `{RULE_INJECT_STATE_DIR}/{session_id}.txt` で、1 行に 1 つのルールの場所を持つ。
フックと MCP サーバーが同じ場所を読み書きする。
最後に書き足してから 30 日を過ぎた記録ファイルは、セッションの開始時に消える（[ルールの案内](../はじめに/コアコンセプト/ルールの案内.md)）。
日数は `RULE_INJECT_RECORD_RETENTION_DAYS` で変えられる。

同じフォルダの `{session_id}.guided.txt` には、止めずに案内したルールの場所を 1 行ずつ持つ。
既読の記録と同じく、圧縮の前とセッションの開始時の掃除で消える。

同じフォルダの `{session_id}.history.jsonl` には、既読にした履歴を 1 行ずつ持つ（[ルールの案内](../はじめに/コアコンセプト/ルールの案内.md)）。
圧縮の前には消えず、最後に書き足してから `RULE_INJECT_RECORD_RETENTION_DAYS` 日を過ぎたものが、セッションの開始時の掃除で消える。

## 変数参照の値

索引の `rule` とルールの本文に書いた `!{名前}` は、同じ名前の環境変数の値に置き換わる（[索引の書式](./索引の書式.md)・[MCPツール](./MCPツール.md)）。
値は、ほかの環境変数と同じく Claude Code の設定の `env` か、Claude Code を起動する側の環境に置く。

## ログの置き場所

`RULE_INJECT_LOG_DIR` には、絶対パスか `~` で始まるパスを書く。
フックと MCP サーバーは、失敗した操作をこのフォルダの `{yyyymmdd}_rule-inject.log`（日付は UTC）へ 1 行ずつ書く。
日付が今日から `RULE_INJECT_LOG_RETENTION_DAYS` 日以上前のファイルは、セッションの開始時に消える。

日数の環境変数に 1 以上の整数でない値を書くと、既定値で動く。
