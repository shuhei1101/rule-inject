# 要件

## 要望

`docs/interface/` のインターフェース定義（IF-122-1〜22）の本文（lead 以外）に、[Issue #99](https://github.com/shuhei1101/rule-inject/issues/99) の手順 3・4・6 を適用する。
書き込みは dev-docs の `write_docs` で行う。

| No | 工程 | 終わりの条件 |
| --- | --- | --- |
| 1 | 文を表へ | 同じ属性を持つ項目が 2 件以上ある文・箇条書きが表になっている。`**キー**: 値` が 3 つ以上並ぶものは「項目 / 値」の表になっている |
| 2 | 文を削り、AI slop を修正する | 既出の言い直し・理由の説明・当たり前の注意が無い。残した文が規約『文章の書き方』の確認表と対応表に沿う |
| 3 | 本文に出さないものの移動 | 本文に検討事項の ID・Issue 番号・文書のパスが生の文字で無い（タイトル付きのリンクか関連のキーにある） |
| 4 | 検査 | 変えた設計書が `write_docs` の検査を通る |

インターフェースの入出力・フローの中身は変えない。
