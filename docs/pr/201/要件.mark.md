# 要件

## 要望

- MCP サーバー `rule-inject` 1 つの設計書を、knowledge のテンプレート『MCP サーバーの定義』（`template-mcp-server`）で `docs/mcp-server/` に作成する。`tools[]` は今のツールを全て並べ、各ツールのインターフェース定義を `tools[].interface` で指す
- スキル `global-setup`・`setup` の設計書を、knowledge のテンプレート『エージェントフロー』（`template-agent-flow`）の `type: skill` で `docs/agent-flow/` に作成する
- 実装を設計書に合わせる。設計書と食い違う MCP サーバーの instructions・ツールの description と、スキルの `SKILL.md` を設計書のとおりに直す
- 種類の行（`mcp_server`・`agent_flow` ほか）は、反映作業『配布先の配信元の設定への種類の行の追加』で `project-index.yaml` へ追加してから設計書を作成する
- 精度評価は対象外とする
- スキルの手順はエージェントフローの設計書を原本にし、`SKILL.md` は設計書から生成する。生成のコマンドを rule-inject に作る（[確認事項](https://github.com/shuhei1101/rule-inject/pull/201#discussion_r4651850840)への 👍 で決定）
