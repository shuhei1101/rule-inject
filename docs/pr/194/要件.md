# 要件

## 要望

rule-inject が mdmark を参照する箇所を、既定では mdmark の develop の最新にし、設定でタグか commit に固定できるようにする。

| 参照する箇所 | 今の参照 | 変えた後 |
| --- | --- | --- |
| `docs/mdmark.config.yaml`・`docs/guide/mdmark.config.yaml` の `version`（設定・文書が合わせてある mdmark のバージョン） | `v0.13.0` | `develop`。固定するときは `v{MAJOR}.{MINOR}.{PATCH}` を記載する |
| `mdmark check` で文書を点検する CLI（テスト実行方法に記載が無い） | 作業ごとに v0.13.0 の CLI | テスト実行方法の lint 層に `npx github:shuhei1101/mdmark#develop check` を記載し、固定するときは `#develop` をタグか commit に替える |
| 公開サイトのテーマが読む mdmark（`docs/_theme/_layouts/default.html`） | 既定で develop の最新（#193 で取り込み済み） | 変えない。固定するときの Pages の設定 `mdmark.version` を `docs/_config.yml` にコメントで記載する |

終わりの条件:

- 2 つの `mdmark.config.yaml` の `version` が `develop` で、develop の CLI の `mdmark check` がずれ 0 件で終わる
- テスト実行方法の lint 層に、develop の最新で点検するコマンドと、固定するときの書き方がある
- `docs/_config.yml` に、公開サイトの mdmark をタグか commit に固定する `mdmark.version` の書き方がある
