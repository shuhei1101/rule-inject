# 要件

## 要望

`rules.yaml` の `read_tool` を持つエントリのルールは、dev-docs の名前（`mcp__plugin_dev-docs_dev-docs__search_docs`）と project-index の名前のどちらで `read_tool.args` と同じ引数の `search_docs` を呼んでも既読になる。

base（develop の `rules.yaml`）のまま満たしているため、`rules.yaml` は変えない。

| 根拠 | 内容 |
| --- | --- |
| dev-docs の `search_docs` の結果 | `view: full` の文書を `<document path="{配信元の直下}/{パス}" scope="full">` で包んで返却する（dev-docs の `2731c0c^:src/dev_docs/features/search/render.py` の `_full`）。knowledge の配信元の直下は `KNOWLEDGE_ROOT` と同じ knowledge の develop の worktree |
| 既読の記録のフック | 結果に `<document>` があれば、全文の文書のパスが索引のルールの場所と同じものを既読にする（`src/rule_inject/hooks/record_read.py` の `_locations_and_method`） |

## 実測

`record_read` に、dev-docs の名前・`python-core-naming` を指す引数・dev-docs の結果の構造の `tool_response` を持つ PostToolUse のペイロードを指定し、既読の記録に載った件数を数えた。

| 索引 | `view` | 既読 |
| --- | --- | --- |
| base（develop） | `full` | ✓ |
| base（develop） | `summary` | |
| 作業ブランチ（`read_by` を加えた `f30af2d`） | `full` | ✓ |
| 作業ブランチ（`read_by` を加えた `f30af2d`） | `summary` | ✓ |

`read_by` を加えると、本文を返却しない `view: summary` の呼び出しでも既読になるため、`f30af2d` は `6d32aa6` で戻した。
