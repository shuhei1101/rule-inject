# 要件

## 要望

`rules.yaml` の `read_tool` を持つエントリは、次のどちらの呼び出しでもそのルールを既読にする。

| 呼び出すツール | 既読にする手段 |
| --- | --- |
| `mcp__plugin_project-index_project-index__search_docs` | 今の `read_tool`（変えない） |
| `mcp__plugin_dev-docs_dev-docs__search_docs` | エントリに加える `read_by`。`tools` にこのツールの名前、`args` に `read_tool.args` と同じ文書を指す `source` と `filter[id]` を記載する |

確認方法: 索引のチェック（`check_indexes`）で違反が無く、dev-docs の名前で `read_tool.args` と同じ引数の `search_docs` を呼んだ後に、そのエントリのルールが既読になる。
