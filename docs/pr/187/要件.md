# 要件

## 要望

`docs/` の Markdown のマーカーを、今の書き方から mdmark の JSON の記載へ移す。

- 手で記載した Markdown（`docs/guide/` と `docs/pr/`）は、mdmark v0.11.0 以降の `mdmark upgrade` で書き換える。移行の報告に挙がる記載（拡張・`libraries` のマーカー、書き出さない記載）は手で記載し直す
- `mdmark upgrade` は配布済みの最新の v0.13.0 まで適用する。v0.13.0 の手順で、廃止した `flow` の範囲（`docs/guide/` の 3 ページ）も map の範囲へ書き換わり、`docs/guide/mdmark.config.yaml` に `map.kinds`・`map.lines` が追加される
- 移行の報告に挙がった `flow` の `scope`・`updated` は、map の範囲に写す先が無いため本文に記載しない。`scope` は図の直前の本文と map の `title` で読み取れ、`updated` は履歴にあたる
- `index.yaml` から生成するフォルダの `README.md` は `mdmark upgrade` で書き換えず、AI Monitor の develop（[shuhei1101/ai-monitor#3418](https://github.com/shuhei1101/ai-monitor/issues/3418) を含む）の `publish` で書き出し直す。`publish` が同時に書き換える `docs/_config.yml` の `exclude` の並びの入れ替えは、マーカーと関係しないため含めない
- 書き換えた後、`mdmark check` が `legacy_mark` を出さない
- マージした後、[shuhei1101/mdmark#478](https://github.com/shuhei1101/mdmark/issues/478) に完了した旨をコメントする
