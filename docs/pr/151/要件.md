# 要件

## 要望

`src`・`tests`・`hooks`・設計書・`docs/guide` に残る AI slop の単語を、規約『文章の書き方』の対応表（knowledge の『AI slop の単語の対応表』）の単語へ置き換える。
対象は docstring・コメント・MCP のツールの説明文・エラーと案内の文言・索引のスキーマの説明・設計書の説明と図のメッセージ・公開ドキュメントの本文で、処理は変えない。

起点 Issue の例の単語は、[PR #141](https://github.com/shuhei1101/rule-inject/pull/141)・[PR #148](https://github.com/shuhei1101/rule-inject/pull/148) の言い回しに合わせる。

| 今の単語 | 新しい単語 |
| --- | --- |
| 当たる（条件に合う意味） | 該当する（照合の結果を指すときはヒットする） |
| 使われている | 使用中・使用されている |
| 書いた後 | 書き込んだ後 |
| 確かめる | 確認する |
| 置き場所 | 配置場所 |

ほかの NG の単語は、対応表の OK の単語へ置き換える。
「読む」と「書く操作」（その失敗の「書けない」を含む）は、このプラグインの単語として維持する。
エラーと案内の文言を変えるときは、その文言を照合するテストの期待値と、文言を記載する設計書・公開ドキュメントを同じ文言に合わせる。
同じ項目を説明するコードと公開ドキュメント（`server/types.py` と `docs/guide/MCPツール.md` など）は、同じ言い回しに統一する。

| 終わりの条件 |
| --- |
| `src`・`tests`・`hooks`・設計書・`docs/guide` に対応表の NG の単語が無い（「読む」「書く操作」と、スコープ外の行を除く） |
| 単体テストと結合テストが全件 pass する |
