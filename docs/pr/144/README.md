# 既存の文書に残る「ルールの注入」を用語「案内」へ置き換える

## 概要

公開ドキュメントの `docs/guide/` に残る「ルールの注入」の言い方を、用語集の用語「案内」の言い方へ置き換える。

## 背景

[Issue #142](https://github.com/shuhei1101/rule-inject/issues/142) の要望。
作業 PR [#140](https://github.com/shuhei1101/rule-inject/pull/140) で新設した用語集 `docs/glossary/GLO-122-1.yaml` は、用語「案内」の `avoid` に「ルールの注入」を入れた。
今の仕組みはルールの本文を差し込まず、場所と参照の方法を案内するため。
既存の文書の置き換えは #140 のスコープ外にした。
