# 要件

## 要望

develop の `docs/guide/` に残る次の 6 か所を、用語「案内」の言い方へ置き換える。
置き換えた後、`docs/guide/` に「注入」が残らない。

| 箇所 | 今の記述 | 置き換え後 |
| --- | --- | --- |
| `docs/guide/files.yml` の `ルールにするか文書にするかを決める.md` の行の `tags` | `topic:ルールの注入` | 既存のタグ `topic:ルールの案内` |
| `docs/guide/files.yml` の同じ行の `description` | 規約・手順を索引へ登録して注入するか | 規約・手順を索引へ登録して案内させるか |
| `docs/guide/index.yaml` の同じページの行の `summary` | 同上 | 同上 |
| `docs/guide/README.md` の同じページの行の概要 | 同上 | 同上 |
| `docs/guide/使い方.md` の同じページの行の概要 | 同上 | 同上 |
| `docs/guide/ルールにするか文書にするかを決める.md` の冒頭リード | 同上 | 同上 |

作業の決まりの「注入」（`SessionStart` でコンテキストへ本文を記載する）は本文を差し込むため、置き換えない。
