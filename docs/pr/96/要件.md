# 要件

## 要望

`src/rule_inject/shared/yaml_lines.py` の要素を持つモジュール構成の設計書 `モジュール構成/shared/yaml_lines.py.yaml` を作る。

- 定数 `LIST_ITEM_MARK`・`QUOTE_CHARS`・`MIN_QUOTED_LENGTH`・`RESERVED_HEADS`、データモデル `Line`、関数 `yaml_error`・`_strip_comment`・`tokenize`・`parse_scalar`・`_split_flow_items`・`parse_flow_list`・`read_block_list`・`split_key`・`read_value` を、`container` を `shared/yaml_lines.py` にして全て載せる
- 要素の中身は develop の実装に合わせ、実装は変えない
- `モジュール構成/shared/index.yaml` に行を追加する
- `src/files.yaml` の `rule_inject/shared/yaml_lines.py` の `related` の `to` を、束ねる設計書 `分類/プラグイン/共通` から作った設計書へ張り直す
- 作った設計書に、書くツール `write_design_doc_module` が `problems` を返さない
- 設計書の `unit_tests` どおりに単体テスト `tests/unit/rule_inject/shared/test_yaml_lines.py` を作り、設計書の `test_files` に載せる
