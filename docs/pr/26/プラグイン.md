## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 共有の fixture | `tests/e2e/conftest.py` に fixture `guidance_count` を足す。`(session_id, snippet)` を受け、記録の行のうち `attachment.type` が `hook_additional_context` で、`attachment.content` の要素のどれかが `snippet` を含む行の数を返す | `attachment.content` が文字列のときは、その文字列で判定する。記録のファイルを探す処理は `transcript_text` と共有する |
| 単一ユースケースの E2E | 二つの `test_normal_when_already_guided` の数え方（各 2 か所）を `guidance_count(session_id, 文面)` に替える | 検証（`guided_count == 1`・`--resume` の後も同じ回数）は変えない |
| `transcript_text` | 変えない | 文面が含まれるか（`in`）で確かめる他のケースが使う |
| 既存機能への影響 | プラグインの実装（フック・MCP サーバー）は変えない | - |
