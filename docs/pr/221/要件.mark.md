# 要件

## 要望

`project-index.yaml` に `direct_commit` を追加し、`branch` を `develop` にして、次の種類を `kinds` で許可する。

| 分類 | 種類 | 指定 |
| --- | --- | --- |
| 設計書・目次 | `architecture`・`nonfunctional`・`scenario`・`interface`・`module`・`config`・`er`・`data`・`external_api`・`library`・`test_procedure`・`layout`・`dev_command`・`agent`・`mcp_server`・`launch`・`agent_flow`・`llm_call`・`evaluation`・`eval_criterion`・`eval_case`・`index` | ID の文字列 |
| 用語集 | `glossary` | ID の文字列 |
| 索引のエントリ | `rule_index` | ID の文字列（書き込みで `rule_index_entry` の検査を通る） |
| 管理用の YAML | `docs`・`src`・`hooks`・`tests`・`skills`・`root` | `{id: …, body: false}`（本文のファイルは書き換えない） |

`prompts`（`content/prompts/` のフックが注入するプロンプト）は、書き換えるとフックの出力が変わる成果物のため許可しない。

マージの後、端末の設定の `sources[]` の `rule-inject` の行に `direct_commit.write_api_kinds` として上の全ての種類を登録し、dev-docs の画面から直コミットできる状態にする（[反映作業](./反映作業/index.yaml)）。
