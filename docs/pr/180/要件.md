# 要件

## 要望

ルール索引（`content_types: [rule_index]`）を直下の `rules.yaml` だけにし、`docs/` の直下から削除する。

| 対象 | 変更 |
| --- | --- |
| `docs/rules.yaml` | 削除する |
| `docs/_root/files.yml` | 唯一の行が `docs/rules.yaml` のため、ファイルごと削除する |
| `project-index.yaml` | 配信元 `docs` の `paths` から `docs/_root/files.yml` を削除する |
| `docs/_config.yml` | `exclude` から `rules.yaml` を削除する |
| `docs/layout/LAY-173-1.yaml` | `docs/rules.yaml` と `docs/_root/` の行を削除する |
| AI Monitor の端末の設定 `~/.config/ai-monitor/settings.yaml` | rule-inject の `rule_indexes` から `docs/rules.yaml` の行を削除する（反映作業） |

直下の `rules.yaml` は端末の設定の `rule_indexes` にも残るため、案内されるルールは変わらない。
