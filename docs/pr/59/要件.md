# 要件

## 要望

- ローカルのクローンから 1 つだけ常駐させ、HTTP で接続する MCP サーバーを追加する
  - 待ち受けのポートは設定ファイルで指定する
  - フックとサーバーは同じ設定ファイル（`settings.yaml`、環境変数 `RULE_INJECT_CONFIG`）を読む
  - 待ち受けるアドレスはループバック（`127.0.0.1`）に限る
- サーバーに次のツールを持たせる
  - 一覧: プロジェクトを渡すと、そのプロジェクトで今効いているルール（読む索引とエントリ）を返す。読めなかった索引と理由・読み飛ばしたエントリと理由・無効のエントリ（`enabled: false`）も返す
  - 検索: ファイルのパスか MCP のツールの呼び出し（ツール名と引数）を渡すと、当たるルールと、未読のときに操作を止めるかを返す
  - チェック: 索引（`rules.yaml`）を JSON Schema（YAML で持つ）に照らして Python の `jsonschema` で検証し、違反と、`rule` の場所にファイルが無いエントリを返す
  - 編集: 索引のエントリを新規作成・編集・削除する。書いた後の索引がチェックに通らないときは書き込まない。`ruamel.yaml` の round-trip で読み書きし、コメント・キーの並び・引用符を保つ
- フックの動作と、索引・設定ファイルの既存のキーは変えない
- サーバーは起動のコマンドで前面で動かし、Ctrl+C か SIGTERM で止める。常駐のさせ方（systemd のユーザーのユニット 等）は使い方に例として載せる
- フックはサーバーに依存せず、今どおり索引を自分で読む。サーバーはフックと同じ照合のコードを使う

## 変更箇所の由来

| 対象箇所 | commit | 目的 | 変更回数 | 影響 |
| --- | --- | --- | --- | --- |
| アーキテクチャ図の制約「常駐するサーバーは持たない」 | [f7f9249](https://github.com/shuhei1101/rule-inject/commit/f7f9249b89d3b88909d7dc5f2e36fcd5731c6c33)（`ファイルに当たるルールを案内する Claude Code プラグインを立ち上げる (#3)`） | 立ち上げ時に、フックだけで動くプラグインとして置いた | 1 回 | [#44](https://github.com/shuhei1101/rule-inject/pull/44)（[3fa7282](https://github.com/shuhei1101/rule-inject/commit/3fa72820d9e76ea64b782dee2311aa3bcb102dbe)）が廃止したのはセッションごとに立つ stdio のサーバーで、HTTP の常駐化の設計は同じ PR で戻した。今回はフックをサーバーに依存させず、1 つだけ常駐させるため、#44 の目的（セッションごとにプロセスを立てない）を壊さない |

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| `paths` がどのファイルにも当たらないエントリのチェック | プロジェクトのファイルを全て辿る必要があり、一覧・検索・チェックの要望と別に重さの見積もりが要る | #64 |
| 既読の記録の確認と削除（セッションごとの既読のルールと読んだ方法・未読に戻す） | サーバーはセッションを持たず、既読の記録の扱い（`features/record`）を新たにスコープへ入れることになる。依頼の「トークンの削除」はこの既読の記録の削除を指し、今回は入れずに起票するとユーザーが決めた（[確認ログ](./確認ログ.md)） | #65 |
| ルールのまとめ取り（`paths` を渡して当たるルールの本文をまとめて返す） | #44 で `read_rules` とともに廃止し、既読はフックだけで付けると決めた。採ると既読の扱いを決め直すことになる | 予定なし |
| 本文の `!{名前}` の展開 | alias-inject へ移した | 予定なし |
| `dev/pr/52/反映作業/index.yaml` がテンプレート『目次』の Schema に合わない（必須キー `summary`・`items` が無く、Schema に無い項目を持つ） | テンプレート『目次』から外れているが、今回の要望に含まれない | #61 |
| プロジェクトの索引として指している直下の `rules.yaml` が無く、フックが毎回読めない旨を出す | 規約『ルール索引への登録』の前提から外れているが、今回の要望に含まれない | #62 |
