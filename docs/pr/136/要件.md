# 要件

## 要望

`docs/module/` のモジュール構成に次をする。
dev-docs の `write_docs` で書き込む。

| 対象 | 内容 |
| --- | --- |
| MOD-122-1〜62 の本文（lead 以外） | [Issue #99](https://github.com/shuhei1101/rule-inject/issues/99) の手順 3・4・6 を適用する |
| ファイル単位の文書 MOD-122-1〜51 | 規約『文書のタグと description の記載』に沿った lead を記載する |

| No | 工程 | 終わりの条件 |
| --- | --- | --- |
| 1 | 文を表へ | 同じ属性を持つ項目が 2 件以上ある文・箇条書きが表になっている。`**キー**: 値` が 3 つ以上並ぶものは「項目 / 値」の表になっている |
| 2 | 文を削り、AI slop を修正する | 既出の言い直し・理由の説明・当たり前の注意が無い。残した文が規約『文章の書き方』の確認表と対応表に沿う |
| 3 | 本文に出さないものの移動 | 本文に検討事項の ID・Issue 番号・文書のパスが生の文字で無い（タイトル付きのリンクか関連のキーにある） |
| 4 | lead の記載 | MOD-122-1〜51 が、何を定めるかとどんなときに参照するかの 1 文（40〜120 字）の lead を持つ |
| 5 | 検査 | 変えた設計書が `write_docs` の検査を通る |

モジュールの関数・クラス・定数の中身は変えない。
