## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| glob の展開 | 読むコマンドの引数のうち、引用符の外に `*` `?` `[` を含むものを、基準のフォルダから `glob.glob`（`recursive=False`、隠しファイルは当てない）で展開し、当たった実在するファイルを名前の順に並べて読む対象にする | 語に分ける前に引用符の中と `\` の直後の `*` `?` `[` を `glob.escape` の形に置き換え、`shlex` は今と同じ `posix=True` で分ける |
| `for` の語の並び | `for {変数} in {語の並び}` の区切りの後の、`do` で始まる区切りから `done` までを `for` の本体とし、本体の読むコマンドが `$変数` / `${変数}` を引数に取るとき、語の並びを読む対象にする | `do` を先頭から外した残りを 1 つのコマンドとして見る。語の並びの glob も展開する |
| 改行の区切り | 引用符の外の改行を `;` と同じコマンドの区切りにする。直前に `\` がある改行（行継続）は区切りにしない。ヒアドキュメントの本文の語は捨てる | 行継続を空白に置き換えてから、改行を記号として `shlex` で分ける（モジュール構成『コマンドの解析』の `extract_read_paths`） |
| 既読の記録 | `FULL_READ_COMMANDS` でも同じ取り出しをする | `record_read.py` の呼び方は変えない |
| 戻り値 | 実在するファイルの絶対パスを出てきた順、重なりなしで返す（今と同じ） | glob で当たったファイルは、glob を書いた位置に名前の順で並べる |
