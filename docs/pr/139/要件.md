# 要件

## 要望

- 公開ドキュメントのフォルダ `docs/guide/` に mdmark の設定 `docs/guide/mdmark.config.yaml` を配置する。キーはスキル `mdmark:setup` で 1 つずつユーザーに確認して決める
- `docs/guide/` の公開ドキュメントに mdmark の `check` を実行し、出た問題を全て修正して、`check` の問題が 0 件になる

配置先を `docs/guide/` にしたのは、`check` の対象が公開ドキュメントの `docs/guide/` だけで、対象と設定が 1 か所にまとまるため。
