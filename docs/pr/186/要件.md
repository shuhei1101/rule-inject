# 要件

## 要望

AI Monitor の配布物の準拠バージョンを v0.3.0 から v0.4.0 へ上げ、追従 Issue の分類ごとに次を満たす。

| 分類 | 満たすこと |
| --- | --- |
| 準拠バージョン | [ai-monitor-version.ini](https://github.com/shuhei1101/rule-inject/blob/20b0bfc/ai-monitor-version.ini) が `v0.4.0` を指す |
| サイトのレイアウト | `python -m ai_monitor.distribution import-site --version v0.4.0` で `docs/_theme/` を取り込み、控え [ai-monitor-theme.yaml](https://github.com/shuhei1101/rule-inject/blob/20b0bfc/ai-monitor-theme.yaml) が v0.4.0 を指す |
| 配信設定 | [docs/_config.yml](https://github.com/shuhei1101/rule-inject/blob/20b0bfc/docs/_config.yml) が v0.4.0 の配布元の `docs/_config.yml` のキーと `exclude` の値を全て持ち、rule-inject の値（`title`・`description`・`baseurl` と、rule-inject だけの `exclude` の値 `glossary/`）を保つ |
| テンプレート・規約・判定・観点 | v0.3.0..v0.4.0 で変わったテンプレート・規約・判定フローチャート・チェックシート・観点を参照し直し、従っていない rule-inject の成果物（`docs/`・ルートの `README.md`・`CLAUDE.md`）を修正する |
| プラグイン | MCP `update_plugins` を呼び、手元の ai-monitor プラグインを v0.4.0 のタグ以降の commit にする（2026-11-15 時点の手元のプラグインは v0.4.0 のタグより前の [1e239c64](https://github.com/shuhei1101/ai-monitor/commit/1e239c6472f3550a44da7b04755b77816aaa89a6)） |
| 配布先の反映作業 | [反映作業](./反映作業/index.yaml) の 8 件を実行し、各作業の確認方法の値が rule-inject で観測できる |

### 配布先の反映作業の dry-run の結果

| 作業 | dry-run | rule-inject の今の状態 |
| --- | --- | --- |
| プロジェクトの索引の移動 | skipped | 直下に `rules.yaml` があり、`docs/rules.yaml` は無い |
| 配布先の移した文書の写しの削除 | skipped | 削除するコピーが無い |
| 配布先の dev-docs への移行 | failed（`dev-docs.yaml` が無い） | 配信元の設定は `project-index.yaml` へ改名済み |
| 配布先のエージェント統合への追従 | skipped | `agent_context.yaml`・`.claude/agent-settings/` を持たない |
| プロジェクトの索引の設定ファイルへの移行 | skipped | `.claude/settings.json` を持たない |
| 各プロジェクトのスキーマの参照への移行 | failed（`dev-docs.yaml` が無い） | `project-index.yaml` の `documents[].schema` は knowledge の参照で、`schemas/` は `common`・`glossary` だけを持つ |
| 配布先の規約のパスの追従 | skipped | `rules.yaml` は AI Monitor の `.md` を指さず、`agent_context.yaml` を持たない |
| 配布先のデータの設計書の作成 | failed（`dev-docs.yaml` が無い） | `docs/data/` に DATA-181-1〜4 がある |

failed の 3 件は、スクリプトが配信元の設定のファイル名を `dev-docs.yaml` に決め打ちしているため止まる（[shuhei1101/ai-monitor#3472](https://github.com/shuhei1101/ai-monitor/issues/3472)）。
この 3 件は、確認方法の `dev-docs.yaml` を `project-index.yaml` に読み替えて確認する。
