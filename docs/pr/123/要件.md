# 要件

## 要望

再起動・更新のツールを呼んだクライアントが、ツールの応答を受け取ってから接続が切れるようにする。

- 停止の待ちは、処理中のツールの呼び出しの応答を送信し終えるまでを処理中として数える
- 対象は停止を始める 2 つのツール（`restart_server`・`update_server`）の呼び出しと、停止の待ちの間に処理中だった呼び出しの全て
  - `restart_server` は `guard` で包まずに登録しているため、停止の待ちは自分の応答の送信を待たない。Issue の事象と同じ型の箇所として含める
- 終わりの条件: 結合テスト `tests/integration/server/test_update_server.py` と `tests/integration/server/test_restart_server.py` のファイル単体の実行を、それぞれ 10 回続けて失敗なしで終える
- インターフェース定義『サーバーの再起動』の制約「待ち受けの閉じ方」の `notes`（処理中の呼び出しは停止の待ちで待ち終えているため、閉じた後に待つのは送信し終えていない応答だけ）を、修正した後の振る舞いに合わせる
