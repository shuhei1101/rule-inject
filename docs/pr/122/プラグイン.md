## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 参照の書き換え | 移す前に AI Monitor の v0.4.0 の変換を `dev/` の置き場所のまま掛け、設計書の参照（`refs`・`inherits`・`detail`・本文のリンク・`click`）をパスから ID へ書き換える | 変換は ai-monitor の [f135cff63](https://github.com/shuhei1101/ai-monitor/commit/f135cff63c1f6b4089f3db4bfdc1b2cb5bcdcb71) 以降の develop で掛ける |
| 設計書の移動 | 変換の後に、設計書を `git mv` で種類のフォルダへ移し、ファイル名を `{ID}.yaml`（モジュール構成・インターフェース定義の `.py.yaml` は `{ID}.py.yaml`）にする | フォルダごとの `index.yaml`・`README.md` は削除する |
| 分類 | 今のサブフォルダ（単一 / 複合ユースケース・プラグイン・`features` などの物理ファイルのフォルダ）を各設計書の `category` へ移す | 分類の値はフォルダ名のまま |
| 公開範囲 | 移した設計書に `visibility: internal` を持たせる | - |
| Schema | `dev/テンプレート/*.schema.yaml` を `schemas/{kind}.schema.yaml` へ移し、`visibility`・`category` を検証で受け付ける | kind の名前は ai-monitor#3307 の種類のフォルダに合わせる |
| 文書を指すパス | `*/files.yaml` の `related` の `to`・`dev-docs.yaml` の `paths`・`schema`・`instructions`・`pyproject.toml` の `exclude` を移動先へ書き換える | - |
| 既存機能への影響 | フック・MCP サーバーのコードとテストのコードは変えない | テストのコードの `dev/` は索引の試験の値で、実在のファイルを指さない |
