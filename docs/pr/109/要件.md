# 要件

## 要望

1. `.claude-plugin/plugin.json` から `version` を削除する（規約『Claude プラグインルール』の `no-version-01`）。`.claude-plugin/marketplace.json` の `plugins[]` にも `version` を置かない
2. 非機能要件『バージョンの一致』と非機能要件テスト `tests/nfr/test_version_consistency.py` から `plugin.json` を除外し、`version.ini`（先頭の `v` を除く）・`pyproject.toml`・`uv.lock`（`rule-inject` のパッケージ）の 3 つの一致を確認する
3. 設計書の `plugin.json` の説明（モジュール構成『フック』・外部ライブラリ『claude-code』）を「名前とバージョン」から「名前」にする
4. バージョンの更新の手順から `plugin.json` を除外する。手順は連絡ボードの `tester` のセクションの行「版上げで plugin.json も揃える」だけが持つため、マージの後にこの行を削除する（反映作業）

非機能要件テストは、3 つの一致に加え、`plugin.json` と `marketplace.json` の `plugins[]` に `version` が無いことも確認する（`version` の再追加で、marketplace から入れた利用者へ更新が届かなくなる不具合（[Issue #24](https://github.com/shuhei1101/rule-inject/issues/24)）を検知する）。
