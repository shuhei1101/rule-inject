# 要件

## 要望

文書の拡張子を `.mark.md` へ改名せず、mdmark の設定の `check.suggestMarkExtension` を `false` にして `plain_md_with_marks` を止める。

- 警告が出る文書のうち、`README.md`（`docs/README.md`・`docs/guide/README.md`・`docs/interface`・`docs/library`・`docs/module`・`docs/scenario` の `README.md`）は AI Monitor の `publish` が `index.yaml` から書き出し、`docs/pr/` の PR ドキュメントは AI Monitor のツールとテンプレートが名前を決める。どちらも名前を改名できないため、設定で止める
- `docs/guide/` の残りの 7 ページも改名せず、同じ設定で止める。改名すると `files.yml`・`index.yaml`・`docs/_theme/_data/nav.project.yml`・ルール索引 `rules.yaml` の `docs/guide/索引の書式.md`・ページ間のリンク・公開ページの URL が変わる
- `docs/guide/mdmark.config.yaml` に `check.suggestMarkExtension: false` を記載する
- `docs/guide/` の外の Markdown（`docs/pr/` と生成物の `README.md`）を点検する mdmark の設定は無く、#187 では一時の設定で点検した。`docs/mdmark.config.yaml` を新設して `docs/guide/` を除いた `docs/` の Markdown を範囲にし、`check.suggestMarkExtension: false` を記載する

終わりの条件:

- `docs/guide/` で流した `mdmark check` が `plain_md_with_marks` を出さない
- `docs/` で流した `mdmark check`（新設した `docs/mdmark.config.yaml`）が `plain_md_with_marks` を出さない
