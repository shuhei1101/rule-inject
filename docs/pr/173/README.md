# フォルダ構成の設計書（layout）を作成し、今のフォルダ構成をレビューの観点で確認する

## 概要

knowledge のテンプレート『フォルダ構成』（layout）の書式で、このリポジトリのフォルダ構成の設計書を 1 枚作成し、レビューの観点で見つかった問題を別の Issue に起票する。

## 背景

[Issue #114](https://github.com/shuhei1101/rule-inject/issues/114) の要望。
このリポジトリにはフォルダ構成の設計書が無く、フォルダ構成の問題をレビューで洗い出せない。
テンプレートは [shuhei1101/knowledge#219](https://github.com/shuhei1101/knowledge/issues/219)、設計の手順は [shuhei1101/ai-monitor#3267](https://github.com/shuhei1101/ai-monitor/issues/3267)、knowledge のスキーマの参照は [shuhei1101/ai-monitor#3188](https://github.com/shuhei1101/ai-monitor/issues/3188) で入った。
