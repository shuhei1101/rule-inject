# 要件

## 要望

シナリオ名に残る AI slop の単語を、規約『文章の書き方』の対応表の単語へ置き換え、名前を参照する `uses`・図の `click` とノードのラベルも同じ名前に書き換える。

| シナリオ | 今の名前 | 新しい名前 |

| 終わりの条件 |
| --- |
| シナリオ名に対応表の NG の単語が無い（「読む」「書く操作」はこのプラグインの語として残す） |
| 名前を参照する `uses`・`click`・インターフェース定義の参照が新しい名前を指し、設計書の検証で参照先の項目が無いエラーが出ない |
| SC-122-16 の本文の「配置場所」とシナリオ名・図の「置き場所」が統一されている |

dev-docs の `write_docs` で記載し、シナリオの流れ・期待値・`test`・`test_file` は変えない。
`{ID}#scenarios[{名前}]` で名前を参照しているのは SC-122-23・24・25 で、変える名前を参照しているのは SC-122-25 だけ（`docs/interface/` からの参照は無い）。
