# 要件

## 要望

リポジトリの直下の配信元の設定 `dev-docs.yaml` を `project-index.yaml` へ改名する（中身は変えない）。

master へ入った後に、端末の設定 `~/.config/dev-docs/settings.yaml` の配信元 rule-inject の `config` を `/mnt/c/Users/shuhe/repo/rule-inject/project-index.yaml` へ書き換え、配信しているサーバーへ読み直させる。
書き換えた後に、`search_docs`（`source`: `rule-inject`・`view`: `count`）の件数が、書き換える前と同じであること。

配信元のワークツリーは、端末の設定の `config` が指すクローン本体の設定から引くため、ワークツリー側の設定のファイル名に依らない（dev-docs の `src/dev_docs/features/access/service.py` の `worktree / source.root.relative_to(source.repo_root)`）。
develop へのマージから master へ入るまでの間は、クローン本体（master）に `dev-docs.yaml` が残り、端末の設定もそれを指すため、配信は止まらない。
