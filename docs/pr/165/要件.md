# 要件

## 要望

リポジトリの直下の配信元の設定 `dev-docs.yaml` を `project-index.yaml` へ改名する（中身は変えない）。

develop へマージした直後に、端末の設定 `~/.config/dev-docs/settings.yaml` の配信元 rule-inject の `config` を `/mnt/c/Users/shuhe/repo/rule-inject/project-index.yaml` へ書き換え、配信している dev-docs に読み直させる。
書き換えた後に、develop の worktree を作業場所にした `search_docs`（`source`: `rule-inject`・`view`: `count`）の件数が、書き換える前と同じであること。

dev-docs は、端末の設定の `config` が指すパスの設定を、クローンの `default_ref`（既定 `develop`）のリビジョンから読む（dev-docs の `src/dev_docs/features/sources/service.py` の `read_default_ref_config`）。
そのため、作業 PR が develop へ入ると `develop:dev-docs.yaml` が無くなり、次の読み直しで rule-inject の配信が止まる。書き換えはマージの直後に行う。
