`publish` は AI Monitor のクローンで `PYTHONPATH=src uv run python -m ai_monitor.design_docs publish --root {作業ツリーの直下}` として実行する。
`publish` は分類のトップページの front matter を `permalink` だけで書き出すため、旧 URL `/使い方/` からの転送は `docs/_config.yml` の `defaults` に `scope.path: guide/使用方法.md` の行を追加し、`values` に `redirect_from: /使い方/` を配置して指定する。

| 終わりの条件 |
| --- |
| 公開ドキュメントの分類名・ページ名・`permalink` が「使用方法」になり、上の表の箇所に「使い方」が無い |
| 手元の Jekyll のビルドで、旧 URL `/使い方/` のページが新 URL `/使用方法/` へ転送する |
| `publish` を `--check` で実行して差分が無い |
