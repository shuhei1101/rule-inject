## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 単一ユースケースの E2E | `test_normal_when_already_read`・`test_error_when_index_unreadable`・`test_error_when_rule_variable_unset` の書く操作の `allow` を `["Write", "Edit"]` にする | 検証は変えない |
| 複合ユースケースの E2E | 3 ケースの書く操作の `allow` に `"Edit"` を足す（93 行目の準備の実行も含む） | 検証は変えない |
| 単一ユースケースのシナリオ | `正常シナリオ（既読のため案内しない）`・`異常シナリオ（索引が読めない）`・`異常シナリオ（ルールの場所の変数参照を展開できない）` のセットアップの `操作` の補足に、`--allowedTools` で Write と Edit を許可することを書き足す | 期待値とフローは変えない |
| 複合ユースケースのシナリオ | 全シナリオのセットアップに、`--allowedTools` で Write と Edit を許可することを書き足す | 期待値とフローは変えない |
| 既存機能への影響 | プラグインの実装（フック・MCP サーバー）は変えない | - |
