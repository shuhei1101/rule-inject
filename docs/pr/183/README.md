# 開発コマンドの設計書を作成し、生成物の生成元と生成するコマンドをフォルダ構成の設計書に記載する

## 概要

開発コマンドの設計書を作成し、フォルダ構成の設計書の生成物・コピーのエントリに生成元と生成するコマンドを記載する。

## 背景

[Issue #176](https://github.com/shuhei1101/rule-inject/issues/176) の要望。
[#173](https://github.com/shuhei1101/rule-inject/pull/173) で作成したフォルダ構成の設計書を規約『フォルダ構成の切り方とレビュー』の観点「管理しないもの」で確認したところ、リポジトリに開発コマンドの設計書が無い。
`generated_from.command` は開発コマンドの分類への参照が必須のため、生成物・コピーのエントリに生成元を記載できない。
