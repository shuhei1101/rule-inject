# 要件

## 要望

- `schemas/glossary.schema.yaml` を新設し、用語集の種類（`x-kind: glossary`・`x-folder: docs/glossary`・`x-id-prefix: GLO`）を定める。用語は `id`・`name`・`description`・`aliases`・`avoid` を持つ
- `docs/glossary/GLO-122-1.yaml`（`visibility: internal`）を新設し、目次 `docs/glossary/index.yaml` と `docs/index.yaml` の行を追加する
- `dev-docs.yaml` の `documents[]` に、用語集を `records: terms`・`alias_type: term` で指す行を追加する
- 判定フローチャート『用語の登録』で「このリポジトリに新しい用語として登録する」と判定した rule-inject の語を登録し、同じものの言い換えを `aliases`（使ってよい言い方）・`avoid`（やめた言い方）に入れる。候補は既読の記録・案内済みの記録・ルール索引・作業の決まりと、設計書・公開ドキュメントの 2 つ以上の文書に出るプロジェクト固有の呼び名
- 終わりの条件: `list_match_words`（`source`: `rule-inject`）が登録した用語の `name`・`aliases` を返し、`search_docs` の `term` で用語が引ける

置き場所は判定フローチャート『ドキュメント配置判定』で `docs/{設計書の種類}`・internal（Schema を持つ種別）、形式は判定フローチャート『データ化判定』で YAML（全行が同じ列を持つ定型で 2 箇所以上から参照される）と決めた。
