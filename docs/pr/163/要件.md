配信元の設定は `dev-docs.yaml` の名前のまま、`$schema` だけを project-index の schema（`schemas/project-index.schema.json`）にする。
[shuhei1101/project-index#27](https://github.com/shuhei1101/project-index/issues/27)（config を `project-index.yaml` へ向けた後に `search_docs` で文書が引けない）が open で、今 rule-inject を配信している dev-docs は `dev-docs.yaml` を読むため、改名はスコープ外へ回す。

`schemas/` の「dev-docs の画面」は、画面が dev-docs に残るため書き換えない（スコープ外）。

| 終わりの条件 |
| --- |
| 上の表の箇所に、配信元・文書としての dev-docs の記述が無い |
| `dev-docs.yaml` の 1 行目の `$schema` が project-index の schema を指し、`dev-docs.yaml` がその schema の検査を通る |
| `publish` を `--check` で実行して差分が無い |
