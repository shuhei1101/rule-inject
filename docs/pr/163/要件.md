`docs/guide/README.md`・`使用方法.md` が `index.yaml` から書き出すページなら、`index.yaml` を直して書き出し直す。

`未確定`: 配信元の設定 [dev-docs.yaml](https://github.com/shuhei1101/rule-inject/blob/beabb2f/dev-docs.yaml) の扱い（決める段: ドキュメント修正）

| 案 | 内容 |
| --- | --- |
| A | `project-index.yaml` へ改名し、1 行目の `$schema` を project-index の schema にする |
| B | `dev-docs.yaml` のまま、1 行目の `$schema` だけを project-index の schema にする |

推奨: A

project-index は、フォルダを渡すと `project-index.yaml` を探し、無ければ移行の間だけ `dev-docs.yaml` を探す（project-index の設計書 CFG-1）。
[shuhei1101/project-index#27](https://github.com/shuhei1101/project-index/issues/27)（config を `project-index.yaml` へ向けた後に `search_docs` で文書が引けない）が open のまま着手した場合は、改名した後に `search_docs` で rule-inject の文書が引けることを確かめ、引けなければ B にする。

| 終わりの条件 |
| --- |
| 上の表の箇所に、配信元・画面としての dev-docs の記述が無い |
| 配信元の設定の 1 行目の `$schema` が project-index の schema を指す |
| 配信元の設定を書き換えた後に、`search_docs` で rule-inject の文書が書き換える前と同じ件数で引ける |
