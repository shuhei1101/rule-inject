## 要望

フロー名は、対応するシナリオの新しい名前（[PR #141](https://github.com/shuhei1101/rule-inject/pull/141)）と同じ言い回しにする。

| 終わりの条件 |
| --- |
| 上の箇所に対応表の NG の単語が無い（「読む」「書く操作」はこのプラグインの語として残す） |
| インターフェース定義のフロー名が、対応するシナリオの新しい名前（#141）と同じ言い回しになっている |
| 制約「…」などでフロー名を参照している箇所が、新しい名前を指している |

Issue #143 の表の今の語句は例のため、表に挙げたインターフェース定義のフロー名・エラー名は、例に無いものも NG の単語を置き換える。「書けない」は書く操作の失敗のため残す。
IF-122-14 の「既定の配置場所の索引」のフローは、`summary`・図の参加者とメッセージと、このフローを参照する `setup` の「置き場所」も「配置場所」に統一する。
エラーの文言を変えるため、文言を照合するテストがあれば同じ文言に合わせる。
