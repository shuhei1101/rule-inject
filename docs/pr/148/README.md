# インターフェース定義のフロー名・シナリオの図・テストとコードの文言に残る AI slop の単語を置き換える

## 概要

インターフェース定義のフロー名とその参照、シナリオの図のメッセージ、結合テストの docstring とコードの文言に残る AI slop の単語を、#138 の新しいシナリオ名と同じ言い回しへ置き換える。

## 背景

[Issue #143](https://github.com/shuhei1101/rule-inject/issues/143) の要望。
[PR #141](https://github.com/shuhei1101/rule-inject/pull/141)（[Issue #138](https://github.com/shuhei1101/rule-inject/issues/138)）はシナリオ名とその参照だけを置き換え、同じ言い回しがインターフェース定義のフロー名・シナリオの図・テストとコードの文言に残っている。
