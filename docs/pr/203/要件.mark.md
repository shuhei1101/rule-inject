# 要件

## 要望

- MCP サーバーの instructions の本文を、プロンプトファイル `content/prompts/mcp/rule-inject/instructions.yaml`（`id`: `mcp/rule-inject/instructions`・`kind`: `instructions`）へ移す
- 全てのツールの description の本文を、ツールごとのプロンプトファイル `content/prompts/mcp/rule-inject/tools/{ツールの名前の _ を - にした名前}.yaml`（`kind`: `tool`）へ移す
- サーバーの組み立て（`build_server`）は、プロンプトファイルを読み込んで `lang` の本文を描画し、`MCPServer` の `instructions` と各ツールの `description` に指定する。`app.py` には本文を残さない
- クライアントが受け取る instructions と各ツールの description の文面は、移す前と一字一句同じにする
- プロンプトファイルは knowledge の規約『プロンプトファイル』の構造に従い、1 行目のモードラインで knowledge の `schemas/prompt.schema.yaml` を指す。配信元の設定 `project-index.yaml` にプロンプトの文書の行を追加し、スキーマで検査できるようにする
- 本文の描画と `when` の評価は jinja2（[外部ライブラリ『jinja2』](../../library/LIB-203-1.yaml)）で行い、MCP サーバーの依存に追加する
