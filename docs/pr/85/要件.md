# 要件

## 要望

モジュール構成「MCPサーバー / サーバー」（`dev/設計書/モジュール構成/MCPサーバー/サーバー.py.yaml`）を、`src/rule_inject/server/` の物理ファイルごとの設計書へ分ける。

- 分けた後の設計書は、どれも要素の `container` が 1 つの物理ファイルだけを指す（`server/types.py`・`server/dev_docs.py`・`server/app.py`・`server/__main__.py`・`server/_format.py`・`server/tools.py`・`server/check_tools.py`・`server/record_tools.py` の 8 つ）
- 要素（列挙・定数・データモデル・関数）の中身は変えずに移す。`DEV_DOCS_TIMEOUT` は #80 で置き直した値のまま移す
- `test_files` は物理ファイルごとの単体テストのファイルを、その物理ファイルの設計書へ移す
- 構成図・ディレクトリ構成と分類全体の決まりは、要素を持たない束ねる設計書に置く
- `サーバー.py.yaml` を削除し、目次 `index.yaml` と `src/files.yaml` の `related` の `to` を分けた設計書へ張り直す
- 分けた設計書のどれにも、書くツール `write_design_doc_module` が `物理ファイルが 2 つ以上あります` を返さない

分けた設計書は、テンプレート『モジュール構成』の置き場所 `モジュール構成/{container}.yaml`（`モジュール構成/server/{物理ファイル}.yaml`）に置き、束ねる設計書を `モジュール構成/分類/MCPサーバー/サーバー.yaml` に置く。
