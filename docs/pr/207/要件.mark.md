### #204 Python のルールの案内

- `rules.yaml` の 9 件（`python-core-naming`・`python-core-type-hint`・`python-core-language-rules`・`python-architecture-layout`・`python-architecture-dependency-management`・`python-shared-logger`・`python-testing-layers`・`python-testing-mock`・`python-core-style`）が、フックの「変数参照を展開できない」を出さずに読み込まれる
- `**/*.py` の作成・編集の前に、9 件のうち `paths` がヒットするルールが案内される

- `rules.yaml` の `!{KNOWLEDGE_ROOT}` は変えず、Claude Code の `env`（`~/.claude/settings.json`）に `KNOWLEDGE_ROOT`（knowledge のクローンの場所）を追加する反映作業 `KNOWLEDGE_ROOT の追加` で、9 件を読み込める状態にする

### #205 フックの注入文のプロンプトファイルへの移行

- フックが Claude Code へ返却する注入文（止める案内・止めない案内・検索結果の案内・サーバーの起動の補助の通知・圧縮の後の通知・既読の記録の失敗の通知・設定ファイルが読めない通知・想定外の例外の通知）の本文を、knowledge の規約『プロンプトファイル』の構造の `kind: hook` のプロンプトファイルへ移し、コードに本文を残さない
- フックが返却する文面は、移す前と一字一句同じにする
- フックの実行環境は標準ライブラリだけのままにする（依存を追加しない）
- プロンプトファイルは配信元の設定 `project-index.yaml` のプロンプトの文書の行で検査できる場所に配置する

- フックはプロンプトファイルを標準ライブラリだけで直接読み込み、本文の `{{ 変数 }}` の置き換えと、変数の名前 1 つの `when` だけを描画する（[モジュール構成『プラグイン / 共通 / prompts.py』](../../module/MOD-207-1.py.yaml)）
