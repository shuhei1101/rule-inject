## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| プロンプトファイル | フックの注入文ごとに `kind: hook` のプロンプトファイルを `content/prompts/` の下に作り、今の文面を `lang: ja` の部品へ移す。変数はサービス名・パス・件数を `{{ 変数 }}` で受ける | id とファイルの配置は knowledge の規約『プロンプトファイル』の決まりに従う |
| 読み込み | フックがプロンプトファイルを id で読み込み、本文を描画して返却する関数をプラグインの共通に配置する。プロンプトファイルの場所はプラグインのルートから導く | 読み込みと描画の仕方は `要件.mark.md` の `未確定` |
| 案内文の組み立て | `features/guidance/service.py` とフックの文面の定数を削除し、読み込んだ本文を使用する | 案内文の字数の上限などの文面でない定数は残す |
| 異常 | プロンプトファイルが無い・読めないときは、操作を止めずに文面を出力せず、ログへ `read_prompt` を記録する。ツールの引数への設定の記入は、許可の理由だけを省いて入力の書き換えを続ける | 通知の文面もプロンプトファイルにあるため、既定の文面を持たない |
| 既存機能への影響 | Claude Code が受け取る注入文の文面は変えない | 既存の単体テストと結合テストの文面の比較で確認する |
| 依存 | フックの実行環境に依存を追加しない | - |
