# 要件

## 要望

`docs/guide/` の次の 3 ページの ` ```mermaid ` のブロックを、mdmark の図の部品で描き直す。
図の種類は規約『表し方の優先順位』の「伝えるものと図の種類」で選び、mdmark にある図（`flow`）で描く。

| ページ | 伝えるもの | 図 |
| --- | --- | --- |
| [コアコンセプト-MCPサーバー](https://github.com/shuhei1101/rule-inject/blob/b93a34d/docs/guide/%E3%82%B3%E3%82%A2%E3%82%B3%E3%83%B3%E3%82%BB%E3%83%97%E3%83%88-MCP%E3%82%B5%E3%83%BC%E3%83%90%E3%83%BC.md) | Claude Code・フック・MCP サーバー・設定ファイル・索引のつながり | 構成図を `flow` で描く |
| [コアコンセプト-ルールの案内](https://github.com/shuhei1101/rule-inject/blob/b93a34d/docs/guide/%E3%82%B3%E3%82%A2%E3%82%B3%E3%83%B3%E3%82%BB%E3%83%97%E3%83%88-%E3%83%AB%E3%83%BC%E3%83%AB%E3%81%AE%E6%A1%88%E5%86%85.md) | ツールを呼んでから案内・既読になるまでの処理の順番と分岐 | フロー図を `flow` で描く |
| [ルールにするか文書にするかを決める](https://github.com/shuhei1101/rule-inject/blob/b93a34d/docs/guide/%E3%83%AB%E3%83%BC%E3%83%AB%E3%81%AB%E3%81%99%E3%82%8B%E3%81%8B%E6%96%87%E6%9B%B8%E3%81%AB%E3%81%99%E3%82%8B%E3%81%8B%E3%82%92%E6%B1%BA%E3%82%81%E3%82%8B.md) | 質問への回答で結果を選ぶ判定の分岐 | テンプレート『判定フローチャート』の描き方で `flow` で描く |

図のノード・線・ラベルは今の Mermaid の図と同じ内容にし、図の外の本文は変えない。
描き直した 3 ページは mdmark の check で問題が出ない。

[計画 Issue #1 のユーザーのコメント](https://github.com/shuhei1101/rule-inject/issues/1#issuecomment-6707024934) のとおり、新しい図 map（[mdmark#324](https://github.com/shuhei1101/mdmark/issues/324)）は待たない。
