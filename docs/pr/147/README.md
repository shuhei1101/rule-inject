# 公開ドキュメント（docs/guide/）の Mermaid の図を mdmark のフロー図へ書き換える

## 概要

`docs/guide/` の 3 ページの Mermaid の図を、mdmark のフロー図（flow）へ書き換える。

## 背景

[Issue #126](https://github.com/shuhei1101/rule-inject/issues/126) の要望。[Issue #99](https://github.com/shuhei1101/rule-inject/issues/99) の作業 PR [#125](https://github.com/shuhei1101/rule-inject/pull/125) で文書を mdmark の書き方へ移行したとき、図の置き換えはユーザーの判断で除外した（[確認事項](https://github.com/shuhei1101/rule-inject/pull/125#discussion_r4528129777)）。インターフェース定義・シナリオの図は [#145](https://github.com/shuhei1101/rule-inject/issues/145) へ切り出した。
