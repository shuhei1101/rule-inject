## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 配信元の設定 | `project-index.yaml` に `generators: [{id: skill-md, run: [project-index, skill-md]}]` と `validators: [{id: skill-md-check, run: [project-index, skill-md, --check]}]` を追加する | 書き方は project-index の配信元の設定と同じ |
| 設計書 | IF-122-24・MOD-122-64〜66 を `delete_docs` で削除し、目次の行を削除する | 参照している側があれば `on_referenced` で確かめる |
| 開発コマンド | CMD-183-1 の 4 を `project-index skill-md`（配信元の直下）に書き換え、確認した記録を書き直す | - |
| コード・テスト | `src/rule_inject/build_skills/`・`src/rule_inject/features/build_skills/` と 3 つのテストファイルを削除し、`src/files.yaml`・`tests/files.yaml`・`pyproject.toml` の行を削除する | - |
| 既存機能への影響 | 切り替えた後に `project-index skill-md` を流し、`skills/` の SKILL.md に差分が出ないことを確かめる | 差分が出たら、組み立ての違いとして要件へ戻す |
