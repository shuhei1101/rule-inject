## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 索引のキー | エントリに `read_by`（要素ごとに `tools`・`args`）を足す。パターンの書き方と引数の照合は案内の当て方の `tools`・`args` と同じ | - |
| フックの登録 | PostToolUse の既読の記録の matcher を `Read\|Bash\|mcp__.*` にする | このプラグイン自身の MCP ツールは対象から外す |
| 既読にする | MCP ツールの呼び出しを、ツール名と引数で索引から引き、当たったエントリのルールの場所をそのセッションの既読の記録へ追記する | 当たらなければ何もしない |
| 既読の履歴 | 既読にした全ての読み方（Read・Bash・`read_rules`・MCP ツール）で、時刻・セッション・読み方・ツール名・ルールの場所を、セッションごとの JSON Lines の履歴ファイルへ追記する。圧縮では捨てず、終わったセッションの掃除で消す | ファイル名と行のキーはインターフェース定義・ER 図で決める |
| エラー返却（フック） | 既読の記録か履歴に書けないときは、書けなかった記録・場所・理由をコンテキストへ載せ、ログに書く。操作は止めない | 既読の記録に書けないときは今と同じ |
| エラー返却（`read_rules`） | 既読の記録に書けないときは今のままエラーを返す。履歴にだけ書けないときは本文を返し、書けなかった場所と理由を応答に載せ、ログに書く | 既読の判定は既読の記録だけで決まり、履歴の欠けは本文を返さない理由にならない |
| 性能 | フックの打ち切り（1 秒）の中で終える。索引に既読にする MCP ツールのエントリが無いときは、MCP ツールの呼び出しで既読の記録を書かない | 非機能要件の実行時間の項目で確かめる |
| 既存機能への影響 | 既存の索引のキーと既読の記録の書式は変えない | 書き足しだけで、今の索引はそのまま読める |
