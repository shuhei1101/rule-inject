# 常駐の MCP サーバーへ状態の確認・再読込・再起動・更新の管理のツールを追加する

## 概要

Claude Code が、常駐の MCP サーバー自身の状態の確認・設定の再読込・再起動・更新を、サーバーの管理の MCP ツールで行えるようにする。

## 背景

[Issue #107](https://github.com/shuhei1101/rule-inject/issues/107) の要望。PR [#106](https://github.com/shuhei1101/rule-inject/pull/106) の `要件.md` の `## スコープ外` から切り出した。
規約『MCP サーバー作成ルール』の `sdk-transport-06` は、常駐サーバーの状態の確認・再読込・再起動・更新を、サーバー自身が出す管理の MCP ツールで行うと定めている。
今のサーバーのツールはルールの一覧・検索・索引のチェックと編集・既読の記録の確認と削除だけで、再起動と更新は利用者が `systemctl --user` とクローンの `git pull`・`uv sync` を手で実行している。
