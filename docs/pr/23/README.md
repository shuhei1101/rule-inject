# E2E が Linux 側へ写したプラグインを読み、フックのタイムアウトを避ける

## 概要

E2E テストが、Linux 側のファイルシステムへ写したプラグインを `claude -p --plugin-dir` に渡し、フックが 1 秒のタイムアウトに収まる状態で案内を確かめられるようにする。

## 背景

[Issue #19](https://github.com/shuhei1101/rule-inject/issues/19) の報告。
release/v0.2.0 の E2E（[#18](https://github.com/shuhei1101/rule-inject/pull/18)）で、案内を確かめる 7 件が、フックの `timeout` 1 秒での打ち切り（`hook_cancelled`）で fail した。
E2E は `--plugin-dir` にリポジトリの直下を渡しており、クローンが `/mnt/c`（WSL から見た Windows のファイルシステム）にあると `hooks/run.py` の起動だけで 0.72〜1.09 秒かかる。
同じ中身を Linux 側へ展開すると 0.06〜0.10 秒で、7 件とも pass した。
切り分けはテスト不備（E2E の実行環境）で、実装と非機能要件「フックの実行時間」は変えない。
