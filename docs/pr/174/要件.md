# 要件

## 要望

`docs/interface/` のインターフェース定義 16 件と `docs/scenario/` のシナリオ 13 件の `flow` の ```` ```mermaid ```` の図を、mdmark の map の図へ書き換える。

- 記載方法は knowledge の Schema（`design-schemas/v8.2.0` の `schemas/design/common.schema.yaml` の `map`）に合わせ、`<!-- map -->` から `<!-- /map -->` の範囲に ```` ```mermaid ```` のコードブロックを 1 つ配置する
- 図の種類は規約『表し方の優先順位』の「伝えるものと図の種類」で選ぶ。単一ユースケースのシナリオとインターフェース定義はやり取りの順番を伝えるため `sequenceDiagram`、複合ユースケースのシナリオは単一ユースケースの連鎖を伝えるため `flowchart TD` のまま残す
- 図の中のノード・メッセージ・`click` の参照は変えない
- 書き換えた後、`docs/interface/` と `docs/scenario/` に map の範囲の外の ```` ```mermaid ```` が残っていない
