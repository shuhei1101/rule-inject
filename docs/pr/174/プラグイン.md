## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `flow` の図 | 各 ```` ```mermaid ```` のコードブロックを `<!-- map -->` と `<!-- /map -->` で囲む。コードブロックの中身は変えない | 補足 `<!-- map-data -->` は配置しない |
| 検査 | `project-index.yaml` を `dev-docs.yaml` の名前で一時的に写した作業ツリーを設計書の検証のコマンドに渡して実行し、写したファイルは commit しない。出力が base ブランチで同じ手順で実行した出力と一致し、書き換えの前後で `flow` の値が map の範囲で囲んだだけになっていることを確認する | 設計書の検証のコマンドは `dev-docs.yaml` を参照するが、このリポジトリは `project-index.yaml` へ改名済み |
