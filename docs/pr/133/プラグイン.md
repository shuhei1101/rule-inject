## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `work_rules` の返却 | `source: compact` で削除できずに残った既読の記録があるときと、設定ファイルが読めないときだけ、その通知を `additionalContext` で返却する | 通知が無いときは標準出力に何も出さず、終了コード 0 |
| `WORK_RULES` | プラグインから削除し、文面は MCP サーバーの instructions に移す | 同じ文を 2 か所に配置しない |
| `work_rules` の名前・ログの `Component.WORK_RULES` | 変えない | `hooks/run.py` の「同じ SessionStart の `work_rules` が通知する」前提も変わらない |
| 単一ユースケース（SC-122-6） | 決まりを MCP サーバーへの接続時の instructions で受け取る流れに修正する | サーバーが止まっていると届かないことを異常シナリオに記載する |
