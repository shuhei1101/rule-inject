# 要件

## 要望

新しいファイルの作り方の決まり（Write で空の内容で作り、案内されたルールを参照してから Edit で中身を記載する）を、SessionStart のフックの `additionalContext` から除外し、MCP サーバーの instructions（MCP の `initialize` の応答の `instructions`）に記載する。

| 対象 | 要件 |
| --- | --- |
| MCP サーバーの instructions | 新しいファイルの作り方の決まりを、規約『注入文の書き分けと書き方』のとおり事実の文で記載する。4,096 字以内 |
| SessionStart のフック `work_rules` | 新しいファイルの作り方の決まりを返却しない。圧縮の後に削除できずに残った既読の記録の通知と、設定ファイルが読めない理由の通知だけを返却するフックとして残す。通知が無いときは `additionalContext` を返却しない |
| 届く範囲 | MCP サーバーに接続したセッションとサブエージェントに届く |

MCP サーバーが止まっているセッションには、この決まりは届かない。
サーバーの起動の補助（`start_server`）で起動を依頼し、`/mcp` で接続し直すと届く。
