# 要件

## 要望

1. `.claude-plugin/plugin.json` の `version` を、マージする時点の develop の `version.ini` の値（先頭の `v` を除く）と同じにする。`pyproject.toml` の `version` も同じ値であることを確かめる
2. release の版上げで、`version.ini`・`pyproject.toml`・`.claude-plugin/plugin.json` の 3 つが同じ値へ更新されるようにする
3. 3 つの値と `uv.lock` の `rule-inject` の `version` が食い違ったら、テストが fail する

2 は、版上げをする tester の手順（AI Monitor の tester『リリースマージ』）が `plugin.json` を揃える対象に入れることで満たす（[ai-monitor#2467](https://github.com/shuhei1101/ai-monitor/issues/2467)）。配布されるまでは、連絡ボードの `tester` の節の行で伝える。
3 は、4 つの一致を確かめる非機能要件テスト（`tests/nfr/test_version_consistency.py`）で満たす。
