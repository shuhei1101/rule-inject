# 要件

## 要望

origin/develop の設計書（`docs/pr` を除く）の `status: planned` の行を 1 行ずつ実装と照合し、実装済みの行から `status` のキーを外す（スキーマ `schemas/common.schema.yaml` の `status` は、書かなければ実装済みとして扱う。`implemented` を書いた設計書は無い）。
照合して実装が無い行は `planned` のまま残し、残した行と理由を計画書に書く。

対象の行は次のとおり。

| 設計書 | 行 |
| --- | --- |
| ARCH-122-1 | サブシステム「MCP サーバー」・外部システム project-index |
| CFG-122-1 | `settings` の 28 行 |
| ER-122-2 | 案内済みの記録・既読の履歴 |
| IF-122-11 | 引数 `include_global`・`cursor` |
| LIB-122-3 | `streamable_http_client` |
| NFR-122-1 | NFR-7・NFR-9〜NFR-16 |

終わりの条件: origin/develop を取り込んだ作業ブランチで `docs/pr` を除いて `status: planned` を検索し、ヒットする行が全て実装の無い行である。
