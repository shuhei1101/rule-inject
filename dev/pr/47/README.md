# MCP の結果に載った文書の場所で既読にし、全文を読んだときだけ既読にし、ルールが変わったら未読に戻す

## 概要

文書の MCP の結果に載った文書の場所と範囲でルールを既読にする。
Read も MCP も、全文を読んだときだけ既読にする。
既読の記録に本文のハッシュを残し、既読の後にルールが変わったら未読に戻す。

## 背景

[Issue #46](https://github.com/shuhei1101/rule-inject/issues/46) の困りごと。
今は MCP のツールで読んだルールを索引の `read_by` に記載したツール名で既読にしており、結果にどの文書が載ったかを見ていない。
Read は `offset`・`limit` で一部だけを読んでも既読になり、既読の後にルールの本文が変わっても既読のまま残る。
[#44](https://github.com/shuhei1101/rule-inject/pull/44) で既読をフックだけで付けるようにしたことを前提にする（knowledge の D-124〜D-126・D-128）。
