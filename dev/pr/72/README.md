# dev-docs の配信元の設定を置き、判定フローチャートのページをタグで引けるようにする

## 概要

dev-docs で文書を検索する人が、ルールにするか文書にするかの判定フローチャートのページをタグで引けるようになる。

## 背景

[Issue #67](https://github.com/shuhei1101/rule-inject/issues/67) の要望。
[Issue #63](https://github.com/shuhei1101/rule-inject/issues/63)（D-110）は判定フローチャートを rule-inject の文書として dev-docs で配信し、タグで引けるようにすることを求めていた。
作業 PR [#66](https://github.com/shuhei1101/rule-inject/pull/66) はページの追加だけを扱い、配信の部分をスコープ外にした。
develop には dev-docs の配信元の設定 `dev-docs.yaml` が無い。

## 計画書

| ファイル | 中身 |
| --- | --- |
| [要件](./要件.md) | 要望の整理・影響するユースケース・更新ドキュメント・スコープ外 |
