## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `plugin.json` の `version` | マージする時点の develop の `version.ini` の値から先頭の `v` を除いた値にする | 作業 PR の最新化で develop の版が上がったら追従する |
| 版の一致のテスト | `version.ini`（先頭の `v` を除く）・`pyproject.toml` の `version`・`plugin.json` の `version`・`uv.lock` の `rule-inject` の `version` が全て同じ値であることを確かめる | 非機能要件テスト `tests/nfr/test_version_consistency.py`。食い違ったら 4 つの値を並べて fail する |
| 版上げで 3 つとも更新させる仕組み | 連絡ボードの `tester` の節に、版上げで `plugin.json` の `version` も揃える行を置く | AI Monitor の tester『リリースマージ』が直る（[ai-monitor#2467](https://github.com/shuhei1101/ai-monitor/issues/2467)）までの間 |
