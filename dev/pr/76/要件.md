# 要件

## 要望

lint 層に、ruff の check と format に加えて型検査と依存の向きの検査を入れ、リポジトリ全体（`src` と `tests`）で違反 0 件にする。

- 型検査に mypy、依存の向きの検査に import-linter を `pyproject.toml` の `dev` グループへ追加し、設定を `pyproject.toml` に置く
- import-linter の契約は、今の import の向き（`hooks` と `server` → `features` → `shared`、`features` の下の機能どうしは import しない）を固定する
- `dev/設計書/テスト/テスト実行方法.yaml` の `layers[lint]` の説明・前提・全件実行を、配布元の `dev/テンプレート/テスト実行方法.schema.yaml` の例（`uv run mypy .` と `uv run lint-imports` を足した 1 コマンド）に合わせる
- 追加した検査で出た既存のコードの誤りを修正する。修正は型の絞り込みと注釈に留め、フック・MCP サーバーの入出力と振る舞いを変えない
