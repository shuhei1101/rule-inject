# テスト実行方法の lint 層へ型検査と依存の向きの検査を追加する

## 概要

lint 層で ruff の check と format に加えて、mypy の型検査と import-linter の依存の向きの検査を流し、検査で出た既存のコードの誤りを修正する。

## 背景

[Issue #75](https://github.com/shuhei1101/rule-inject/issues/75) の要望。
[PR #74](https://github.com/shuhei1101/rule-inject/pull/74)（AI Monitor v0.3.0 への追従）の[レビュー指摘](https://github.com/shuhei1101/rule-inject/pull/74#discussion_r4416587419)から切り出した。
v0.3.0 の `dev/テンプレート/テスト実行方法.schema.yaml` は `lint` 層に型検査と依存の向きの検査を求めるが、`dev/設計書/テスト/テスト実行方法.yaml` の `layers[lint]` と `pyproject.toml` の `dev` グループは ruff だけを持つ。
develop の `src` に mypy を既定の厳しさで流すと、12 ファイルで 29 件の誤りが出る。
