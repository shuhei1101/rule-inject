# dev-docs への問い合わせの待ち時間を 1,000 回の実測の p99.9 で置き直す

## 概要

`check_indexes` が dev-docs の応答を待つ時間の上限を、1,000 回の実測の p99.9 から求めた値で置き直す。

## 背景

[Issue #78](https://github.com/shuhei1101/rule-inject/issues/78) の要望。
[#77](https://github.com/shuhei1101/rule-inject/pull/77) で追加した非機能要件「dev-docs への問い合わせの待ち時間」（108 秒）は、`search_docs` が 1 回に 30〜70 秒かかるため 1,000 回を測らず、実測 22 回の最大 71.9 秒を仮の p99.9 に置いている。
この進め方は #77 の確認事項でユーザーが承認した（[スレッド](https://github.com/shuhei1101/rule-inject/pull/77#discussion_r4421349151)）。
