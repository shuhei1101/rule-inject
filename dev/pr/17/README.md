# 索引の既定の置き場所・変数参照の展開・検索結果への案内を足す

## 概要

ai-monitor のルール注入を rule-inject に置き換えられるよう、索引の既定の置き場所・ルールの本文と索引の `rule` の変数参照の展開・検索結果に出たファイルへの案内・止めない案内のセッションで 1 回への絞り込みを足す。

## 背景

[Issue #16](https://github.com/shuhei1101/rule-inject/issues/16) の要望。
ai-monitor はプラグイン ai-monitor のフックとモニターの `read_docs_pages` でルールを注入しており、索引の既定の置き場所・`!{名前}` の展開・検索結果への案内・止めない案内の回数の絞り込みは ai-monitor 側にだけある。
rule-inject は ai-monitor を知らないまま、環境変数だけで同じ働きをする必要がある。
