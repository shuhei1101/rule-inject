# 要件

## 要望

ai-monitor のルール注入をプラグインで置き換えられるよう、次の機能を足す。
プラグインは ai-monitor を知らないまま、環境変数だけで動く形を保つ。

- 索引の既定の置き場所: `RULE_INJECT_INDEXES_USER` が無いときは `${XDG_CONFIG_HOME:-~/.config}/rule-inject/rules.yaml`、`RULE_INJECT_INDEXES_PROJECT` が無いときは `${CLAUDE_PROJECT_DIR}/rules.yaml` を索引として読む。既定のファイルが無ければ、理由を載せずに読まない（環境変数で指したパスが読めないときは、今のとおり理由を載せる）
- 本文の変数参照の展開: `read_rules` が本文の `!{名前}`（名前は `[A-Za-z_][A-Za-z0-9_]*`）を MCP サーバーの環境変数で展開する
  - 空の値は空文字に展開する
  - 未設定の名前は `!{名前}` のまま残し、本文の先頭に「次の変数参照は、環境変数が設定されていないため展開していない: {名前の並び}」の注釈を 1 行足す
  - 応答の上限（非機能要件「MCPのツールの応答の大きさ」）は展開後の本文で数える
  - 既読の記録は展開の前後で変わらない場所で記録する
- 索引の `rule` の変数参照: 索引の `rule` の `!{名前}` を本文と同じ規則で展開する。展開できない名前が残ったエントリは読み飛ばし、理由をコンテキストに載せる
- 検索結果への案内: `PostToolUse` で、Grep・Glob・検索の Bash（`grep` `rg` `find` `ls`）の結果に出た実在するファイルに当たる、未読で未案内のルールを、止めずに案内する（読むかは任意と伝える）
- 止めない案内の回数: 止めない案内は、ルールごとにセッションで 1 回だけ出す。案内した場所を `{RULE_INJECT_STATE_DIR}/{session_id}.guided.txt` に記録し、圧縮と掃除で既読の記録と一緒に消す
- 変えないもの: 索引の書式（除外のキーは `exclude` のまま）、`read_rules` の引数と戻り値の形、既読の記録とログの環境変数
- フックの実行時間は非機能要件「フックの実行時間」に、案内文は非機能要件「フックの案内文の長さ」に収める

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| ai-monitor 側の置き換え（プラグイン ai-monitor のフックを外す・起動時の環境変数・`read_docs_pages` の利用箇所・設定の見直し） | ai-monitor のリポジトリで扱う変更で、このリポジトリの成果物ではない | 予定なし |
| `PreToolUse` で Glob を照合する | 要望に含まれない。Glob の入力はパターンで触るファイルが決まらないため、結果に出たファイルを `PostToolUse` で案内する | 予定なし |
| プロジェクトの名乗り（ヘッダー）・GitHub への照会・GitHub の blob URL の変換 | 要望で入れないと決めている | 予定なし |
