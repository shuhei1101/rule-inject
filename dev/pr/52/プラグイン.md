## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設定ファイルの場所 | `RULE_INJECT_CONFIG` の値（先頭の `~` をホームに展開）を読む。無いときは設定なしで既定値を使う | 既定値は今の環境変数が無いときの値（索引は `~/.config/rule-inject/rules.yaml` とプロジェクトの直下の `rules.yaml`、フォルダは XDG の状態フォルダの下、保持日数は 30 日と 3 日） |
| 設定ファイルのキー | `global` は索引の場所の並び・記録フォルダ・ログのフォルダ・2 つの保持日数を持つ。`projects[]` の要素は `match` と索引の場所の並びだけを持つ | - |
| `projects` の当て方 | `match` が絶対パスなら `CLAUDE_PROJECT_DIR` がその配下のとき、プロジェクト名ならリポジトリのフォルダ名が一致したときに当てる。`.claude/worktrees/` の下は本体で見る。当たった要素を並びの順に `global` へ重ね、並びは後ろに足す | 規約『claudeプラグイン』の `## 設定ファイル` のとおり |
| 相対パス | `projects` の中の相対パスは起動したプロジェクトの直下から解く | `global` の相対パスは設定ファイルの誤り |
| YAML の読み取り | 標準ライブラリだけで動く今の方式を保ち、設定ファイルの構造を読めるよう拡張する | 依存を追加しない（アーキテクチャ図のランタイムは標準ライブラリだけ） |
| 読めない設定ファイル | 指したファイルが無い・読めない・知らないキーを持つときは、索引を読めないときと同じく理由を案内とログに出す。黙って既定値にしない | 規約『コーディング全般』のフォールバック仕様 |
| 今の環境変数 6 個 | 読まない。読み分けの分岐と移行を促す案内は持たない | `要件.md` の決定（A） |
