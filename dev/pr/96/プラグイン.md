## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設計書の新設 | 書くツールの `create` で `モジュール構成/shared/yaml_lines.py.yaml` を作り、定数・データモデル `Line`・関数を develop の実装どおりに書く | 先頭 `_` の関数は `scope: internal` |
| 単体テスト | 設計書の `unit_tests` どおりに `tests/unit/rule_inject/shared/test_yaml_lines.py` を作り、設計書の `test_files` に載せる | 先頭 `_` の関数は `tokenize`・`parse_flow_list` のテストで確かめる |
| 目次 | `モジュール構成/shared/index.yaml` に `yaml_lines.py.yaml` の行を追加する | - |
| 参照の張り直し | `src/files.yaml` の `rule_inject/shared/yaml_lines.py` の `related` の `to` を `dev/設計書/モジュール構成/shared/yaml_lines.py` へ置き換える | - |
| 既存機能への影響 | ソースコード・インターフェース定義は変えない | - |
