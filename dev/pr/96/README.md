# モジュール構成に shared/yaml_lines.py の要素の設計書を作る

## 概要

`src/rule_inject/shared/yaml_lines.py` の要素を持つモジュール構成の設計書を作り、`src/files.yaml` の `related` をその設計書へ張り直す。

## 背景

[Issue #92](https://github.com/shuhei1101/rule-inject/issues/92) の要望。
`shared/yaml_lines.py` の定数・クラス・関数は、モジュール構成のどの設計書にも `container` として載っていない。
[#91](https://github.com/shuhei1101/rule-inject/pull/91) で設計書を物理ファイルごとに分けたときに見つかり、`src/files.yaml` の `related` は束ねる設計書 `分類/プラグイン/共通` を指したままになっている。
