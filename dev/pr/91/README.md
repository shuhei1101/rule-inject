# モジュール構成の残りの 8 つの設計書を物理ファイルごとの設計書へ分ける

## 概要

モジュール構成の残りの 8 つの設計書を物理ファイルごとの設計書へ分け、書くツール `write_design_doc_module` で書き込めるようにする。

## 背景

[Issue #86](https://github.com/shuhei1101/rule-inject/issues/86) の要望。
`MCPサーバー/` の 2 つと `プラグイン/` の 6 つのモジュール構成の設計書は、要素の `container` に 2 つ以上の物理ファイルを持つ。
AI Monitor のテンプレート『モジュール構成』の「1 ファイル = 物理ファイル 1 つ」から外れており、書くツールが `物理ファイルが 2 つ以上あります` の検証で書き込みを止める。
[#85](https://github.com/shuhei1101/rule-inject/pull/85) で `MCPサーバー/サーバー.py.yaml` を同じ方法で分けた。
