## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設計書の分割 | 要素を `container` ごとに `モジュール構成/{container}.yaml`（`hooks/`・`shared/`・`features/index/`・`features/record/`・`features/guidance/`・`features/document/` の下）の設計書へ移す。書くツールの `create` で作る | プラグインの直下の `hooks/run.py` は `モジュール構成/hooks/run.py.yaml` に置く（`src/rule_inject/hooks/run.py` は無く置き場所がぶつからず、プラグインの直下であることは `container` の括弧書きが表す） |
| 束ねる設計書 | `lead`・`directory`・`notes` を、要素を持たない束ねる設計書 `モジュール構成/分類/プラグイン/{フック,共通,索引,既読の記録,案内,MCPの結果の文書}.yaml` へ移す | - |
| 単体テストのファイル | `test_files` を物理ファイルごとに対応する設計書へ移す | 単体テストのファイルを持たない物理ファイルの設計書は `test_files` を持たない |
| 参照の張り直し | `src/files.yaml` の `related` の `to` を分けた設計書へ置き換える。`hooks/files.yaml` の `run.py` は `hooks/run.py` の設計書、`hooks.json` は束ねる設計書 `分類/プラグイン/フック` へ置き換える | `shared/yaml_lines.py` は要素の設計を持たないため、束ねる設計書 `分類/プラグイン/共通` へ置き換える |
| 目次 | 新しいフォルダに `index.yaml` を置き、`モジュール構成/index.yaml`・`分類/index.yaml` に行を追加し、`プラグイン/index.yaml` から分けた 6 つの行を削除する | - |
| 既存機能への影響 | ソースコード・テスト・インターフェース定義は変えない | - |
