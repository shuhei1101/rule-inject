# ファイルに当たるルールを案内する Claude Code プラグインを立ち上げる

## 概要

Claude Code がファイルを触る前に、そのファイルに当たる未読のルールをコンテキストへ案内できるようになる。
ルールは同梱せず、どのプロジェクト・端末にもこのプラグインだけを持っていけば使える。

## 背景

[Issue #2](https://github.com/shuhei1101/rule-inject/issues/2) の要望。
設計書も実装も無いリポジトリで、プラグインを新しく立ち上げる。
[参考の実装](https://github.com/shuhei1101/ai-monitor/tree/develop/plugins/rule-inject/hooks) は特定の開発基盤に依存しているため、その依存を外して作り直す。
