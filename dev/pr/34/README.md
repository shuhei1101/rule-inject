# MCP ツールの引数（タグ・文書の種類を含む）でもルールを当て、照合に正規表現を使えるようにする

## 概要

索引の利用者が、MCP ツールの引数のキーと値（タグ・文書の種類を含む）でルールを当てられ、`paths`・`tools`・引数のパターンに正規表現を書けるようになる。

## 背景

[Issue #31](https://github.com/shuhei1101/rule-inject/issues/31) の要望。
索引の `tools` は MCP ツールの完全名に当てる glob だけで、同じ検索・取得ツールで特定のファイル名・文書 ID・タグ・文書の種類を扱うときだけルールを読ませることができない。
文書を YAML にして MCP 経由で読み書きする方針（[shuhei1101/knowledge#42](https://github.com/shuhei1101/knowledge/issues/42)）になり、ファイルのパスではなくツールの引数で当てる場面が増える。
knowledge のワークスペース `tmp/mcpベストプラクティス検討` の D-34（引数の値で当て、正規表現を使う）と D-20（タグ・種類で当てる。MCP 経由では引数の照合で実現する）で決めた。
