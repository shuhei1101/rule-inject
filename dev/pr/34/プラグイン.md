## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 索引の読み取り | エントリのキーに引数のパターンを足す | `args` は引数のキー → パターンのリストのマップ |
| 正規表現の書き分け | 書き分けの印を持つパターンを正規表現として読み、それ以外は今の glob として読む | 印は `re:`。正規表現は部分一致（`re.search`）で照合する |
| 正規表現の読み込み | 索引を読むときにコンパイルする。コンパイルできないパターンを持つエントリは読み飛ばし、索引の場所・パターン・理由を知らせの文とログに回す | 既存の読み飛ばし（`rule` の変数参照を展開できない）と同じ経路 |
| 引数の照合 | `tools` に当たったエントリのうち、引数のパターンを持つものは、書いた全てのキーの値が当たるときだけ当てる | キーが引数に無ければ当てない |
| 引数の値の扱い | 配列は要素ごとに照合し、どれか 1 つが当たれば当てる。文字列以外のスカラーは文字列にして照合する。オブジェクトの子はドットで結んだキーで指す | オブジェクトそのもの（子を指さないキー）は照合しない。文字列以外のスカラーは JSON の表記（`true`・`null`・`1.5`）で文字列にする。ドット区切りのキーの途中が配列なら要素ごとにたどり、どれか 1 つが当たれば当てる |
| ルール案内のフック | MCP ツールのとき `tool_input` を照合へ渡す | このプラグイン自身のツールを案内しないのは今のまま |
| 既存の索引への影響 | 引数のパターンも正規表現も書かないエントリは、今と同じに当たる | 単体テストで確かめる |
| 性能 | フックの実行時間の決定値（1 秒）を変えない | 正規表現は索引を読むときに 1 回だけコンパイルする。非機能要件テストは `args` を持つエントリ 231 件（実測の索引と同じ件数）と、照合する引数の値 100,000 字の条件で測り直す。超えたときの挙動は『フックの実行時間』の `overflow` のとおり |
