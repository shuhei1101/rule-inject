# MCP ツールの呼び出しでもルールを既読にし、既読の履歴を閲覧の記録として残す

## 概要

索引の利用者が、ルールを読む MCP ツールと引数のパターンをエントリに書け、その呼び出しでルールが既読になる。
既読の履歴が、関連する文書の推薦などほかの仕組みから読める形で残る。

## 背景

[Issue #32](https://github.com/shuhei1101/rule-inject/issues/32) の要望。
既読は Read・Bash の読むコマンド・`read_rules` の呼び出しだけで判定しており、文書を MCP の取得ツールで読む運用（[shuhei1101/knowledge#42](https://github.com/shuhei1101/knowledge/issues/42)）では、同じルールを読んでも既読にならず、二重に読ませる。
knowledge のワークスペース `tmp/mcpベストプラクティス検討` の D-33（MCP ツールと引数のパターンで既読にし、履歴を閲覧の記録として使う）と D-27（閲覧の記録を関連の推薦の信号にする）で決めた。
MCP ツールの引数でルールを当てる照合（`args`・`re:` の正規表現）は [#34](https://github.com/shuhei1101/rule-inject/pull/34) で develop に入っている。
