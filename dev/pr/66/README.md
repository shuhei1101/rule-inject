# ルールにして注入するか dev-docs の文書にするかの判定フローチャートを使い方に追加する

## 概要

規約・手順を書いた人が、rule-inject の索引へ登録して注入するか、dev-docs の文書にしてタグで読ませるかを、判定フローチャートで決められるようになる。

## 背景

[Issue #63](https://github.com/shuhei1101/rule-inject/issues/63) の要望。
話し合い（A-16）で「強制注入を残す基準」の 4 つを決め、満たさないルールは rules.yaml から外して dev-docs のタグで引く方針にした（D-92・D-107）。
基準はどこにも置いていないため、判定の対象を持つ rule-inject に判定フローチャートとして置く（D-110）。
