# 要件

## 要望

- `tests/integration/server/` の結合テストが、他のプロセスが同じポートを取っても失敗しないようにする
  - 対象は `conftest.py` の `free_port`（`start_fake_dev_docs` と各テストが使う）と `_start_shared`（`shared_server` / `limited_server` が使う）
  - サーバー・偽の dev-docs の起動待ちは、別のプロセスが待ち受けていても待ち受けたとみなさない（`MCPError: Not Found` で失敗しない）
  - `free_port` の番号をそのまま使う次のテストも対象に含め、他のプロセスが同じポートを取っても期待値が崩れないようにする
    - `test_server_start.py` の `test_normal`・`test_normal_when_port_overridden`（`port_is_listening(config_port) is False`）・`test_normal_when_stopped`（停止後の `port_is_listening(port) is False`）・`test_error_when_port_in_use`・`test_error_when_settings_unreadable`（`ConnectionRefusedError`）
    - `test_check_indexes.py` の `test_normal_when_dev_docs_unreachable`（何も待ち受けていない接続先の URL）
- `uv run pytest tests/integration` を、別のプロセスが `tests/integration` を同時に流している間に 3 回流して、3 回とも全 pass する
