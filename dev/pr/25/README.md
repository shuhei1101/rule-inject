# E2E の書く操作が通る確かめで、作業の決まりに従う Edit を許可する

## 概要

書く操作が通ることを確かめる E2E のケースで、Write に加えて Edit を許可する。

## 背景

[Issue #20](https://github.com/shuhei1101/rule-inject/issues/20) の報告。
release/v0.2.0 の E2E（[#18](https://github.com/shuhei1101/rule-inject/pull/18)）で、`test_error_when_index_unreadable` と `test_error_when_rule_variable_unset` が `denied_tools` に Edit が載って fail した。
モデルがプラグインの作業の決まりに従って Write（空）→ Edit と進めたが、テストが Write だけを許可していた。
