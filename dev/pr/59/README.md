# ローカルで常駐させる MCP サーバー（HTTP）を追加し、ルールの確認・検索・索引のチェックと編集をツールで行えるようにする

## 概要

利用者が、ローカルで常駐させた 1 つの MCP サーバーに HTTP で接続し、効いているルールの確認・ルールの検索・索引のチェックと編集をツールで行えるようになる。

## 背景

[Issue #58](https://github.com/shuhei1101/rule-inject/issues/58) の要望（依頼元は [PR #57](https://github.com/shuhei1101/rule-inject/pull/57) のレビュースレッド）。
今の rule-inject はフックだけで動き、MCP サーバーを持たない。
stdio の MCP サーバーと `read_rules` は、セッションごとにサーバーのプロセスが立たないように [#44](https://github.com/shuhei1101/rule-inject/pull/44) で廃止した。
#57 で無効のエントリを出す点検のコマンドは作らないと決めたうえで、ルールや索引の状態をツールで確かめ・編集する手段がほしい。
今回はセッションごとに立てず、ローカルのクローンから 1 つだけ常駐させ、HTTP の MCP で接続する。
