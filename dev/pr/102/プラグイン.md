## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 索引のキー | エントリに、ルールを参照する MCP のツールの完全名と引数の値を記載する任意のキーを追加する。記載の無いエントリは今のまま読む | `未確定`（[要件](./要件.md) の `## 要望`。決める段: インターフェース定義設計） |
| 案内文の文面 | 参照方法を記載したルールは、ツールの完全名と引数を先に、代わりの Read の場所を後に載せる。記載の無いルールは今の文面のまま | 文面はユーザーの目に触れるため、インターフェース定義設計の合格後にユーザーへ確認する |
| 同じルールを指す複数のエントリ | 当たったエントリの参照方法を、重複を除いてルールの場所ごとにまとめる | |
| 案内文の上限 | 参照方法の行も `GUIDANCE_LIMIT` に含め、載せきれないルールは今と同じく件数だけを添える | 載せたルールだけを案内済みにする（`shown`）扱いは変えない |
| 既読の判定 | 案内のキーに記載したツール名と引数に一致する呼び出しは、結果の範囲（`scope`）と `read_by` によらず、そのエントリのルールを既読にする | 一致しない呼び出しは今の照合のまま |
