## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `plugin.json` の `version` | キーを削除する | marketplace から入れた利用者へは、Claude Code が commit で更新を判定して届ける |
| 非機能要件『バージョンの一致』 | `version.ini`（先頭の `v` を除く）・`pyproject.toml` の `version`・`uv.lock` の `rule-inject` の `version` の 3 つの一致にする | `未確定`（[要件](./要件.md) の `## 要望`）: `plugin.json`・`marketplace.json` に `version` が無いことも確認するか |
| 非機能要件テスト | `tests/nfr/test_version_consistency.py` を非機能要件の 3 つの一致に合わせて修正する。食い違ったら 3 つの値を並べて fail する | |
| バージョンの更新の手順 | 連絡ボードの `tester` のセクションの行「版上げで plugin.json も揃える」を、マージの後に削除する | 反映作業 `連絡ボードの行の削除` |
