# plugin.json の version を削除し、バージョンの一致の対象から除外する

## 概要

`.claude-plugin/plugin.json` の `version` を削除し、バージョンの一致の非機能要件とそのテスト、バージョンの更新の手順から `plugin.json` を除外する。

## 背景

[Issue #108](https://github.com/shuhei1101/rule-inject/issues/108) の要望。
規約『Claude プラグインルール』の `no-version-01` は、`.claude-plugin/marketplace.json` に載るプラグインは `plugins[].version` と `plugin.json` の `version` のどちらにも version を置かないと定めている。
`plugin.json` の `version` は、[PR #28](https://github.com/shuhei1101/rule-inject/pull/28) で `version.ini` と同じ値にし、非機能要件『バージョンの一致』で食い違いを検知している。
作業 PR [#106](https://github.com/shuhei1101/rule-inject/pull/106) の要件.md の `## スコープ外` から切り出された。
