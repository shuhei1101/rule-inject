# 要件

## 要望

develop から、今ある E2E のテストと、E2E だけが使用する部品を削除する。
設計書のシナリオと、シナリオの `test_file` は残す。

| 対象 | 扱い |
| --- | --- |
| `tests/e2e/`（conftest と単一・複合ユースケースのテスト） | 削除する |
| `tests/files.yaml` の `e2e/` の行 | 削除する |
| テスト実行方法の E2E テストの行 | 削除する |
| 外部ライブラリ（mcp・claude-code）の E2E を指す記述 | 削除する |
| インターフェース定義（端末のセットアップ・索引の登録）の「E2E で確認する」の記述 | E2E を削除した後の記述に修正する |
| シナリオと `test_file` | 維持する |
| 結合テストも使用する部品（`mcp` の依存など） | 維持する |

終わりの条件:

- `tests/e2e/` が develop に無い
- `tests/files.yaml` と `dev/設計書/` に、削除した E2E のテストを指す記述が `test_file` のほかに無い
- 単体テストと結合テストが全て pass する
- 設計書の検証と `tests/files.yaml` の点検が、シナリオの `test_file` の指すファイルが無いことで止まらない
