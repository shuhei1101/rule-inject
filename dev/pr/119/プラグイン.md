## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| E2E のテスト | `tests/e2e/` を丸ごと削除する | MCP サーバーの E2E テストも同じフォルダで消える |
| テストのメタデータ | `tests/files.yaml` から `path` が `e2e/` で始まる行を削除する | 他の行は変えない |
| テスト実行方法 | `E2E テスト` の行を削除する | 結合テスト（バック）の補足が E2E の行を参照していれば合わせて修正する |
| インターフェース定義 | Mock の「シナリオ『…』の E2E で確認する」を、スキルの手順を確かめる自動のテストが無い旨に修正する | 2 ページ |
| 外部ライブラリ | claude-code の `used_in`・説明に E2E を指す記述があれば削除する | 動作確認の履歴（`verification`）は過去の事実のため残す |
| 回帰の確認 | 単体テストと結合テストを全て実行して pass を確認する | 設計書の検証と `tests/files.yaml` の点検も実行する |
