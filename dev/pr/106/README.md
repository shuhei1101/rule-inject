# 端末の設定の既定のパスと環境変数を統一し、MCP をプラグインで配り、セットアップのスキルを作る

## 概要

利用者が環境変数を書かなくても端末の設定を読め、プラグインを入れるだけで MCP サーバーへ接続でき、セットアップをスキルで実行できるようにする。

## 背景

[Issue #105](https://github.com/shuhei1101/rule-inject/issues/105) の要望。検討事項 D-145〜D-147 で、自作のツールの設定の置き場所・環境変数の名前・MCP の配り方・セットアップのスキルを統一すると決めた。
今は `RULE_INJECT_CONFIG` が無いと端末の設定を読まず、MCP は `claude mcp add` で登録し、セットアップのスキルが無い。
`claude mcp add` は PR [#59](https://github.com/shuhei1101/rule-inject/pull/59) が `global.server_port` との食い違いを避けるために選んだ登録の方法で、この PR でその判断を見直す。
