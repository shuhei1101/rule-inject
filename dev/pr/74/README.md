# AI Monitor v0.3.0 の配布物へ追従する

## 概要

rule-inject が準拠する AI Monitor の配布物を v0.2.0 から v0.3.0 へ上げ、成果物を v0.3.0 の Schema・規約・判定フローチャートに合わせる。

## 背景

[Issue #73](https://github.com/shuhei1101/rule-inject/issues/73) の要望。
AI Monitor の v0.3.0 のタグで配布物が変わり、配布元が追従 Issue を起票した。
develop の [ai-monitor-version.ini](https://github.com/shuhei1101/rule-inject/blob/develop/ai-monitor-version.ini) は `v0.2.0` のままで、`dev/テンプレート/*.schema.yaml` は v0.2.0 とも v0.3.0 とも揃っていない（9 ファイルは v0.3.0 と一致し、7 ファイルは v0.2.0 と v0.3.0 の間の配布元の commit と一致する）。
公開サイトは GitHub Pages（develop の `docs/`）で配信しているが、サイトのレイアウト `docs/_theme/` と配信設定 `docs/_config.yml` を持たない。
