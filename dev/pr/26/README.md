# E2E の案内の回数を、記録の案内の行だけで数える

## 概要

案内済みのルールが再び案内されないことを確かめる E2E のケースで、案内の回数を、セッションの記録の案内の行（`hook_additional_context`）だけで数える。

## 背景

[Issue #21](https://github.com/shuhei1101/rule-inject/issues/21) の報告。
release/v0.2.0 の E2E（[#18](https://github.com/shuhei1101/rule-inject/pull/18)）で、二つの `test_normal_when_already_guided` が `assert guided_count == 1` で fail した（`2 == 1`）。
Claude Code 2.1.296 の記録は、案内の行が `attachment.content` に加えて `rendered[].content` に写しを持ち、記録の全文を `str.count` で数えるテストが 1 回の案内を 2 回と数えていた。
