# 要件

## 要望

E2E テストは、プラグインを動かすのに要るファイルをテストの実行ごとに 1 回、Linux 側のファイルシステム（pytest の一時フォルダ）へ写し、写したフォルダを `claude -p --plugin-dir` に渡す。
クローンが `/mnt/c` にあっても、案内を確かめる 7 件（[Issue #19](https://github.com/shuhei1101/rule-inject/issues/19) の一覧）が、フックの `timeout` 1 秒で打ち切られずに pass する。
クローンの置き場所を Linux 側へ移すことは E2E の前提にしない。
テスト実行方法の E2E テストの説明を、写したフォルダを渡す形に合わせる。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 非機能要件「フックの実行時間」の `timeout` 1 秒の見直し | 利用者はプラグインを marketplace から Linux 側へ入れる前提で、`/mnt/c` から読むのは E2E だけのため | 予定なし |
| E2E の Write の確かめで Edit が許可されない fail | 同じ release の別の原因の fail | [#20](https://github.com/shuhei1101/rule-inject/issues/20) |
| E2E の案内の回数の数え方の fail | 同じ release の別の原因の fail | [#21](https://github.com/shuhei1101/rule-inject/issues/21) |
| E2E の変数参照の注釈のエスケープの fail | 同じ release の別の原因の fail | [#22](https://github.com/shuhei1101/rule-inject/issues/22) |
