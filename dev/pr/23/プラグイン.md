## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| プラグインの写し | session スコープの fixture で、`PROJECT_ROOT` から `.claude-plugin/`・`hooks/`・`src/`・`.mcp.json`・`pyproject.toml`・`uv.lock`・`.python-version` を `tmp_path_factory` の下の 1 つのフォルダへ写す | `.venv`・`__pycache__` は写さない。テストの実行ごとに 1 回だけ写す |
| `run_claude` | `--plugin-dir` に写したフォルダを渡す | `cwd`・`env` など他の引数は変えない |
| 進行の記録の `release_head` | 今のまま `PROJECT_ROOT` で `git rev-parse HEAD` を取る | 写したフォルダは git の管理下に無い |
| テスト実行方法 | E2E テストの `description` の `--plugin-dir` の値を「Linux 側の一時フォルダへ写したプラグインのフォルダ」にし、`prerequisites` にクローンが `/mnt/c` にあっても写したフォルダを読むことを 1 行で足す | `write_design_doc_test_procedure` で書く |
