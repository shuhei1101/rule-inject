# 要件

## 要望

dev-docs の既定の接続先を末尾に `/` の付いた `/mcp/` に揃え、単体テストと E2E テストが使うポートを、他のプロセスとの取り合いで失敗しない取り方にする。

| Issue | 終わりの条件 |
| --- | --- |
| [#82](https://github.com/shuhei1101/rule-inject/issues/82) | 既定の接続先（`src/rule_inject/shared/settings.py` の `DEFAULT_DEV_DOCS_URL`）と、`settings.sample.yaml`・`docs/リファレンス/設定ファイル.md` の `dev_docs_url` の値が `http://127.0.0.1:8781/mcp/` になり、設定を置かずに `check_indexes` が dev-docs に接続できる |
| [#88](https://github.com/shuhei1101/rule-inject/issues/88) | `tests/e2e/conftest.py` の `free_port` と `tests/unit/rule_inject/server/test_dev_docs.py` の `test_fetch_used_tags_when_unreachable` のポートの取り方が、#87 で決めた結合テストの取り方に揃い、他のプロセスとの取り合いで失敗しない |

### #82: 既定の接続先

- 次の箇所の `http://127.0.0.1:8781/mcp` を `http://127.0.0.1:8781/mcp/` にする
  - `src/rule_inject/shared/settings.py` の `DEFAULT_DEV_DOCS_URL`
  - `settings.sample.yaml` の `dev_docs_url` とそのコメントの既定
  - `docs/リファレンス/設定ファイル.md` の `dev_docs_url` の行
  - 設計書の設定『プラグイン』の `dev_docs_url` の既定、モジュール構成『shared / settings.py』の定数の値と単体テストの期待値、外部 API『dev-docs』の既定のベース URL
  - 既定の値を期待する単体テスト（`tests/unit/rule_inject/shared/test_settings.py`）と、`tests/unit/rule_inject/server/test_dev_docs.py` の `DEV_DOCS_URL`
- 設定を置かずに起動したサーバーの `check_indexes` が、手元で常駐している dev-docs から使われているタグを引き、`tag_check` が `checked` になる

### #88: テストのポートの取り方

#87 で結合テストに入れた取り方に揃える。

- サーバー・偽の dev-docs の起動は、子プロセスの標準エラーに `Uvicorn running on http://127.0.0.1:{ポート}` が出たことで確かめ、待ち受けに失敗して子プロセスが終わったら別の空いているポートで起動し直す（`tests/e2e/conftest.py` の `free_port`・`resident_server`・`serve`・`start_dev_docs`）
- 「何も待ち受けていない接続先」は、テストが `SO_REUSEADDR` を付けずにポート 0 で bind し、listen しないまま握っている番号の URL にする（`test_dev_docs.py` の `test_fetch_used_tags_when_unreachable`、E2E の `test_check_indexes.py` の `test_error_when_dev_docs_unreachable`）
- 「使われているポート」は、テストがポート 0 で待ち受けて握ったポートを設定ファイルに書く（E2E の `test_run_resident_mcp_server.py` の `test_error_when_port_in_use`）
- `free_port` の番号を後から確かめる次の E2E のテストも、他のプロセスが同じポートを取っても期待値が崩れない確かめ方にする
  - `test_run_resident_mcp_server.py` の `test_normal`（`addresses_listening(port)`）・`test_normal_when_stopped`（停止後の `port_is_listening(port) is False`）・`test_error_when_settings_unreadable`（`ConnectionRefusedError`）
- `uv run pytest tests/unit` を全 pass させ、`free_port`・`serve` を使う E2E のテストを全 pass させる
