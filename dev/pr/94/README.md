# 単体テストと E2E テストのポートの取り方を修正し、他のプロセスとの取り合いで失敗しないようにする

## 概要

単体テストと E2E テストが他のプロセスとのポートの取り合いで失敗しないようにする。

## 背景

[Issue #93](https://github.com/shuhei1101/rule-inject/issues/93) の要望で、子 Issue [#88](https://github.com/shuhei1101/rule-inject/issues/88) を扱う。
子 Issue [#82](https://github.com/shuhei1101/rule-inject/issues/82)（既定の接続先）は、dev-docs#63 で `/mcp` へ接続できるようになったため、ユーザーの判断でスコープから外した（[確認ログ](./確認ログ.md)）。
単体テストと E2E テストは、空いているポートを一度待ち受けてすぐ閉じ、番号だけを使っているため、閉じてから使うまでの間に他のプロセスが同じポートを取ると失敗する（#88）。
結合テストの同じ取り方は [#87](https://github.com/shuhei1101/rule-inject/pull/87) で修正済み。
