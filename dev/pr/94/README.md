# dev-docs の既定の接続先を /mcp/ に揃え、単体テストと E2E テストのポートの取り方を修正する

## 概要

設定を置かずに `check_indexes` が dev-docs に接続できるようにし、単体テストと E2E テストが他のプロセスとのポートの取り合いで失敗しないようにする。

## 背景

[Issue #93](https://github.com/shuhei1101/rule-inject/issues/93) の要望で、子 Issue [#82](https://github.com/shuhei1101/rule-inject/issues/82) と [#88](https://github.com/shuhei1101/rule-inject/issues/88) を合わせて扱う。
dev-docs は末尾の `/` の無い `/mcp` への POST に 405 を返すため、既定の接続先 `http://127.0.0.1:8781/mcp` のままでは `check_indexes` の `tag_check` が常に `skipped` になる（#82）。
単体テストと E2E テストは、空いているポートを一度待ち受けてすぐ閉じ、番号だけを使っているため、閉じてから使うまでの間に他のプロセスが同じポートを取ると失敗する（#88）。
結合テストの同じ取り方は [#87](https://github.com/shuhei1101/rule-inject/pull/87) で修正済み。
