# 文書と文言の語を、語の選び方の規約に合わせて修正する

## 概要

このリポジトリの文書・フックが返す文言・コードのコメントの語を、knowledge の語の選び方の規約に合わせて修正する。

## 背景

[Issue #33](https://github.com/shuhei1101/rule-inject/issues/33) の要望。
見出し・表の列名・項目名に「消す」「形」「足す」「版」などの和語・一字の語が多く、読み手が元の語を推測しないと意味が決まらない。
語の選び方の規約は [shuhei1101/knowledge#34](https://github.com/shuhei1101/knowledge/issues/34) で入り、knowledge の文書の修正（[shuhei1101/knowledge#46](https://github.com/shuhei1101/knowledge/issues/46)）も済んでいる。
エージェントが読む文書が和語を多く使うと出力もそれに寄るため、規約を入れるだけでなく、読ませている元の文書も修正する。
