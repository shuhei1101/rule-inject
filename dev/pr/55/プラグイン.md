## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| シナリオ・インターフェース定義・モジュール構成の設計書 | 項目名・論理名・`title`・`summary`・`lead` と文章の語を `要件.md` の `## 要望` のとおりに修正する。書くツール（`write_design_doc_{kind}` の `replace`・`replace_in_design_docs`）で書き換える | 流れ・期待値・引数・戻り値・例外の中身は変えない |
| 設計書の改名 | 設計書のパス・項目名に対象の語が無いため、改名しない | 改名が要る語が見つかったら、書くツールの `rename` で参照元も修正する |
| 表示する文言 | 案内文・失敗の知らせ・YAML のエラーメッセージ・Python のバージョンの知らせのうち、対象の語を含むものを規約『入力と文言』の語と書式に修正する（例: `` `キー: 値` の形で書いてください `` の「形」） | 文言を変えたメッセージは、モジュール構成の設計書と単体テストの期待値も同じ文言に揃える |
| コメント・docstring | `src/`・`hooks/` のコメントと docstring、`hooks/hooks.json` の `_description` を、モジュール構成の設計書と同じ語に揃えて修正する | 識別子・定数名は変えない |
| テストのコメント・docstring | `tests/` のコメントと docstring を修正する。E2E のプロンプトの「答えてください」は自然な文のため変えない | テスト関数名・アサーションの対象は、文言を変えたメッセージを除いて変えない |
