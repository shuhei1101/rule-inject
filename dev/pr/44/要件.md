# 要件

## 要望

- MCP サーバーを HTTP（Streamable HTTP）の常駐サーバーに移し、stdio をやめる
  - `python -m rule_inject.server` で常駐サーバーを起動し、`127.0.0.1` の `/mcp` で待ち受ける
  - 並行する複数のセッションが 1 つのサーバーのプロセスを共有して `read_rules` を呼べる
  - ツール関数はモジュール変数にセッションごとの状態を持たない
- 待ち受けのポートの既定値は 8783 とし、環境変数 `RULE_INJECT_PORT` で上書きできる
  - サーバーは起動時に `RULE_INJECT_PORT` を読み、無ければ 8783 で待ち受ける
  - `.mcp.json` は `"type": "http"` と `"url": "http://127.0.0.1:${RULE_INJECT_PORT:-8783}/mcp"` で書く
- 常駐サーバーにはセッションの環境変数（`CLAUDE_PROJECT_DIR`・プロジェクトの `.claude/settings.json` の `env`）が渡らない。今のセッションごとの値で引いている索引とルールの場所を、常駐サーバーでも同じ結果で引ける
  - セッションごとの値は PreToolUse フック（今の `session_id` の付与）でツールの引数へ入れる
- 常駐サーバーの起動・停止・ポートの確認の手順を使い方のページに書く
- 今の利用者がプラグインを上げたときに要る操作（常駐サーバーの起動）を使い方のページに書く
- プラグインを上げるたびに、常駐サーバーを止め、新しいバージョンのプラグインのフォルダから起動し直す手順を使い方のページに書く

`未確定`: 常駐サーバーへ渡すセッションごとの値の範囲（決める段: インターフェース定義設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | フックが `CLAUDE_PROJECT_DIR` と、索引の環境変数（`RULE_INJECT_INDEXES_PROJECT` ほか）・ルールの場所の `!{名前}` の展開に使う環境変数・既読の記録とログの置き場所（`RULE_INJECT_STATE_DIR`・`RULE_INJECT_LOG_DIR`）を引数へ入れ、サーバーはその値で索引を引き、既読の記録とログを書く | stdio のときと同じ索引・同じ展開の結果になり、フックと同じ既読の記録を読み書きする | 引数に入れる環境変数の範囲を決める必要がある。引数が大きくなる |
| B | フックが `CLAUDE_PROJECT_DIR` だけを引数へ入れ、他の環境変数はサーバーを起動した環境の値を使う | 引数が小さい | プロジェクトの `.claude/settings.json` に置いた `RULE_INJECT_INDEXES_PROJECT` と `!{名前}` の値がサーバーに効かず、stdio のときと結果が変わる |

推奨: A

プロジェクトの `.claude/settings.json` で索引を指す使い方（`docs/使い方/セットアップ.md` の手順 3）を、常駐サーバーでも今のまま使えるため。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| ポートの上書きを環境変数から `~/.config/rule-inject/config.yaml` に移す | 利用者ごとの設定の持ち方の変更で、D-95（ポートの上書きをどこに書くか）が未決定。Issue の要望は `RULE_INJECT_PORT` の環境変数 | [#39](https://github.com/shuhei1101/rule-inject/issues/39) |
| MCP のプラグインを `{リポジトリ}-docs` として別のプラグインに分ける（D-82・D-83） | 対象は開発ドキュメントサーバーにつなぐ文書の MCP で、rule-inject の `read_rules` は文書の MCP ではない。`.mcp.json` はリポジトリ直下だが、プラグインのルート（`marketplace.json` の `source` が `./`）の `.mcp.json` で、規約のプラグイン用の登録に当たる | 予定なし |
| 常駐サーバーを OS の起動時やセッションの開始時に自動で起動する | Issue の要望は起動の手順を使い方のページに書くまで | 予定なし |
| E2E テストが置く文書を返す MCP サーバー `docs`（`tests/e2e/conftest.py`）を HTTP にする | テストの中だけで立てる差し替えのサーバーで、利用者に配る MCP サーバーではない | 予定なし |
