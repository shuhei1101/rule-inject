# 要件

## 要望

- MCP サーバーと MCP のツール `read_rules` を廃止し、セッションごとに MCP サーバーのプロセスが立たないようにする
  - `.mcp.json` と `src/rule_inject/server/` を削除する
  - `read_rules` のためだけにある PreToolUse フック（セッションIDの付与）を削除する
- ルールの本文は Read で読み、既読はフックだけで付ける
  - 止める案内・止めない案内の文面を「`read_rules` に渡す」から「Read で読む」に変える
  - 既読の記録のフックから、`read_rules` が既読を書くための分岐を外す。既読にする条件（Read・Bash・`read_by`）は変えない
- `read_rules` が持っていた次の機能は無くす
  - 本文の `!{名前}` の展開（alias-inject へ移す: [shuhei1101/alias-inject#11](https://github.com/shuhei1101/alias-inject/issues/11)）
  - `https://` の URL のルールの本文の取得
  - `paths` を渡してのまとめ取りと、応答の上限を超えた分の `deferred`
  - 索引に載っていない場所を読まない制限
