## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 本文の読み方 | 案内に載った場所を Read で読む。既読は既読の記録のフック（Read・Bash・`read_by`）だけが付ける | 案内 → 読む → やり直す、の流れは変わらない |
| 案内の文面 | 止める案内は「Read で読んでから同じ操作をやり直す」、止めない案内は「読む場合は Read で読む」にする | |
| 索引の URL のルール | Read で読めないため、索引の書式から `rule` に URL を書ける記述を外す | 既存の索引に URL が残っている場合の扱いはインターフェース定義の設計で決める |
| 実装の着手 | alias-inject#11 が閉じてから実装する。設計とドキュメント修正は先に進める | 先に廃止すると、ai-monitor のエージェントが `!{名前}` のままの規約を読む |
