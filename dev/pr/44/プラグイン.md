## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| トランスポート | `mcp.streamable_http_app()` の Streamable HTTP で、`127.0.0.1` の `/mcp` を待ち受ける常駐サーバーにする。stdio の起動は残さない | knowledge『MCP サーバー作成ルール』 |
| ポート | 起動時に `RULE_INJECT_PORT` を読み、無ければ 8783。1〜65535 の整数でない値は起動時にエラーで止める | ポートが使われているときは起動時にエラーで止め、ポートの番号を出す |
| 登録 | `.mcp.json` を `"type": "http"` と `"url": "http://127.0.0.1:${RULE_INJECT_PORT:-8783}/mcp"` にし、`command`・`args`・`env` を外す | `alwaysLoad` は付けない（毎ターン使うツールではない） |
| セッションごとの値 | 今の `session_id` の付与のフックが、フックのプロセスの環境変数のうち `RULE_INJECT_` で始まる名前・`XDG_` で始まる名前・`CLAUDE_PROJECT_DIR`・`HOME` と `RULE_INJECT_EXPAND_VARS` に列挙した名前を `session_env` として引数へ足し、サーバーはその値で索引を引き、`!{名前}` を展開する | 引数は待ち受けのポートにいるプロセスへ届くため、秘密の値を載せないよう名前で絞る |
| 状態 | ツール関数はモジュール変数に状態を持たない。既読の記録はこれまでどおりセッションごとのファイルに置く | 既読の記録・ログの置き場所（`RULE_INJECT_STATE_DIR`・`RULE_INJECT_LOG_DIR`）もセッションごとの値としてフックが引数へ入れ、サーバーはその値で書く |
| エラー返却 | 常駐サーバーが起動していないときは、Claude Code の MCP の接続の失敗になる。フックの止める案内は今のまま `read_rules` が使えないときに Read で読む案内を持つ | フックの挙動は変えない |
| 起動の手順 | 起動（`uv run --project {プラグインのフォルダ} python -m rule_inject.server` を常駐させる）・停止・ポートの確認と、プラグインを上げるたびに止めて新しいバージョンのフォルダから起動し直す操作を使い方に書く | プラグインのフォルダの求め方は使い方に書く |
| 既存機能への影響 | `read_rules` の引数（`locations`・`paths`）と応答の書式は変えない | 足すのはフックが入れる引数だけ |
