# ルール案内の変数参照の異常系で他のエントリへの影響を確かめ、rule の無いエントリの扱いの記述を実装に合わせる

## 概要

ルール案内の異常系「ルールの場所の変数参照を展開できない」で、読み飛ばしが他のエントリに及ばないことを期待値とテストで確かめられるようにする。
索引の利用者が、`rule` の無いエントリを書いたときの扱いを、設定の設計書と索引の書式から実装どおりに読める。

## 背景

[Issue #41](https://github.com/shuhei1101/rule-inject/issues/41) は次の 2 件を束ねた親 Issue。

- [#37](https://github.com/shuhei1101/rule-inject/issues/37): [#34](https://github.com/shuhei1101/rule-inject/pull/34) のレビューで見つかった対象外の規約逸脱。異常系「ルールの場所の変数参照を展開できない・止めずに理由を載せる」の通常のエントリが `**/*.md` に当たり、入力の `.py` のパスに当たらない。そのため、実装が誤って索引ごと捨ててもテストが通る
- [#40](https://github.com/shuhei1101/rule-inject/issues/40): [#38](https://github.com/shuhei1101/rule-inject/pull/38) のレビューで見つかった対象外の逸脱。設定の設計書と索引の書式は `rule` の無いエントリを「読み飛ばす」と書くが、実装は行番号つきの ValueError にして索引全体を読まない
