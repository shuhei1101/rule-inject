## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 実測 | `check_indexes` を手元の実際の索引 3 件（エントリ 152 件。`project_dir` は knowledge の develop の worktree）で 1,000 回、1 回ずつ順に呼び、1 回ごとに全体の時間とファイルを辿る時間を測る。全体から辿る時間を引いた残りを内側の待ち以外の処理の時間とした。結果は 1,000 回とも成功で、p50 0.657 秒・p99.9 2.864 秒・最大 3.025 秒 | スクリプト・設定ファイル・結果は `dev/pr/90/実測/`（`measure.py`・`settings.yaml`・`check_indexes.jsonl`）。区間の中の待ちを測らないよう、dev-docs の問い合わせは使われているタグが 0 件の応答をすぐ返す偽の関数に差し替えた（全てのパターンが使われていない、照合の最も重い場合） |
| 1 回の呼び出しの所要時間の上限 | 207 + 2.864 = 209.864 を秒に切り上げた 210 秒にする。`notes` の余裕の説明を、測った回数・条件・p99.9 に置き換える | 規約『資源の値の決め方』の「入れ子の待ち」 |
| 公開ドキュメント | `docs/リファレンス/MCPツール.md` の所要時間を同じ値にする | 値が変わる場合 |
