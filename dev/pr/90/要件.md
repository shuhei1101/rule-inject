# 要件

## 要望

- `check_indexes` の 1 回の呼び出しのうち、内側の待ち（dev-docs への問い合わせとファイルを辿るのを並べて行う区間）以外の処理の時間を 1,000 回測り、p99.9 を出す
  - 内側の待ち以外の処理は、索引の読み取り・JSON Schema への照合・ルールの場所の実在の確かめ・タグのパターンの取り出し（区間の前）と、使われていないタグのパターンの照合・結果の組み立て（区間の後）
  - 1 回ずつ順に呼ぶ
- インターフェース定義「索引のチェック」の制約「問い合わせと辿る順」の 1 回の呼び出しの所要時間の上限を、内側の待ち（207 秒）+ 測った p99.9 を秒に切り上げた値で置き直し、`notes` の余裕の説明を実測の値と測った条件に置き換える（規約『資源の値の決め方』の「入れ子の待ち」）
- 値が変わる場合は、`docs/リファレンス/MCPツール.md` の `check_indexes` の所要時間（311 秒）を同じ値にする
