# 索引のチェックの 1 回の呼び出しの所要時間の上限の余裕を、内側の待ち以外の処理の実測で置き直す

## 概要

`check_indexes` の 1 回の呼び出しの所要時間の上限の余裕を、内側の待ち以外の処理の 1,000 回の実測の p99.9 で置き直す。

## 背景

[Issue #84](https://github.com/shuhei1101/rule-inject/issues/84) の要望。
[#80](https://github.com/shuhei1101/rule-inject/pull/80) で所要時間の上限を 311 秒（dev-docs の待ち時間 207 秒 + 余裕 103.5 秒の切り上げ）に置き直した。
余裕は内側の待ち以外の処理の実測が無いため、規約『資源の値の決め方』の既定どおり内側の待ちの 50% を仮に置いている。
