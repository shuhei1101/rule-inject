# E2E の変数参照の注釈の確かめを、ツールの結果をほどいてから本文の先頭で行う

## 概要

本文に変数参照があるルールの本文を取得する E2E のケースで、注釈の確かめを、ツールの結果をほどいて取り出した本文の先頭の行で行う。

## 背景

[Issue #22](https://github.com/shuhei1101/rule-inject/issues/22) の報告。
release/v0.2.0 の E2E（[#18](https://github.com/shuhei1101/rule-inject/pull/18)）で、`test_normal_when_body_has_variables` が注釈の文面の確かめで fail した。
`read_rules` のツールの結果はページの JSON を文字列として入れ子に持ち、本文の引用符と改行が 2 段エスケープされているが、テストは 1 段のエスケープの文面を探していた。
