# 要件

## 要望

プラグインのログを日付ごとのファイルに分け、古い日付のファイルをプラグインが消す。

- ログは `{yyyymmdd}_rule-inject.log`（日付は UTC）のファイルに、日付ごとに分けて書く
- ログを置くフォルダを環境変数 `RULE_INJECT_LOG_DIR` で変えられる。既定は `${XDG_STATE_HOME:-~/.local/state}/rule-inject/logs`
- セッションの開始時に、日付が今日から保持日数以上前のログのファイルを消す。保持日数は既定 3 日で、環境変数 `RULE_INJECT_LOG_RETENTION_DAYS` で変えられる
- 既読の記録の保持期間（既定 30 日）も、環境変数 `RULE_INJECT_RECORD_RETENTION_DAYS` で変えられる
- 日数の環境変数が 1 以上の整数でないときは、その掃除を飛ばしてログに書く（既定値で黙って動かない）
- 記録フォルダに残った変更前のログ（`{RULE_INJECT_STATE_DIR}/rule-inject.log`）も、セッションの開始時に消す
- セットアップの手順に、ログのフォルダと保持日数・既読の記録の保持期間を変える段を足す
- 消している間に別のセッションが書いた失敗の行を失わない
- 消せなかったときは Claude Code の操作を止めず、ER 図「ログ」の形で失敗を残す（ログに書けなければ標準エラー出力へ出す）
- フックの実行時間は非機能要件「フックの実行時間」（1 秒）に収める
