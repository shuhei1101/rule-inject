# 要件

## 要望

プラグインのログ（`{RULE_INJECT_STATE_DIR}/rule-inject.log`）の古い内容を、プラグインが消す。

- 失敗が続いても、ログが利用者が手で消すまで増え続けない
- 消した後も、直近の失敗は後から追える
- ログを消している間に別のセッションが書いた失敗の行を失わない
- 消せなかったときは Claude Code の操作を止めず、ER 図「ログ」の形で失敗を残す（ログに書けなければ標準エラー出力へ出す）
- フックの実行時間は非機能要件「フックの実行時間」（1 秒）に収める

消す契機・消す単位（ファイルごとか行ごとか）・保持の値は設計で確定する。
