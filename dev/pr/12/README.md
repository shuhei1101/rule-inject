# プラグインのログ（rule-inject.log）を掃除する

## 概要

プラグインのログが日付ごとのファイルに分かれ、利用者が手で消さなくても古い日付のものから消えるようになる。

## 背景

[Issue #11](https://github.com/shuhei1101/rule-inject/issues/11) の要望。
ログは失敗した操作のたびに 1 行追記されるだけで、プラグインは消さない。
[PR #9](https://github.com/shuhei1101/rule-inject/pull/9)（[Issue #5](https://github.com/shuhei1101/rule-inject/issues/5) の既読の記録の掃除）の要件で、判断が分かれるとしてスコープ外にした項目。
