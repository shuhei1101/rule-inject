# 要件

## 要望

圧縮しないまま終わったセッションの既読の記録ファイル（`{RULE_INJECT_STATE_DIR}/{session_id}.txt`）を、プラグインが消す。

- セッションが圧縮しないまま終わったとき、そのセッションの記録ファイルが残り続けない
- 終わりをフックが受け取れなかったセッション（強制終了など）の記録ファイルも、決めた期間を過ぎたら消える
- 進行中の別のセッションの記録ファイルは消さない
- 消せなかったときは Claude Code の操作を止めず、ER 図「ログ」の形でログへ書く
- フックの実行時間は非機能要件「フックの実行時間」（1 秒）に収める

消す契機・残ったファイルの見分け方・期間の値は設計で確定する。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| ログ（`{RULE_INJECT_STATE_DIR}/rule-inject.log`）の掃除 | 判断が分かれる。ER 図「ログ」の保持期間は「掃除は既読の記録と合わせて」と書くが、Issue は既読の記録ファイルだけを挙げ、ログは失敗のときだけ書くため数十行のオーダーにとどまる。含めない判断で、レビューで確定する | 起票予定 |
