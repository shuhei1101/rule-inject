# 圧縮しないまま終わったセッションの既読の記録を掃除する

## 概要

圧縮しないまま終わったセッションの既読の記録ファイルが、残り続けずに消えるようになる。

## 背景

[Issue #5](https://github.com/shuhei1101/rule-inject/issues/5) の要望。
既読の記録ファイルは `PreCompact` フックが圧縮の前に捨てるだけで、圧縮しないまま終わったセッションのファイルは残り続ける。
[PR #3](https://github.com/shuhei1101/rule-inject/pull/3)（[Issue #2](https://github.com/shuhei1101/rule-inject/issues/2) のプラグインの立ち上げ）の要件で、要望に含まれないとしてスコープ外にした項目。
