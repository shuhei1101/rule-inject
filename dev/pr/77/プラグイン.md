## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 照合 | 条件の木の `and`・`or` を入れ子までたどり、`field` が書いた値の条件の `values` を照合する値にする | 書き方は設計で決める。`not` の扱いは `要件.md` の `## 要望` の `未確定` |
| 既存の書き方 | ドットの道筋のキーの照合は変えない | 今の索引の照合の結果を変えない |
| 読み取りと Schema | フックの読み取りと JSON Schema の両方で新しい書き方を受け付ける | Schema が受け付ける範囲はフックの読み取りの内側に保つ（`docs/リファレンス/索引の書式.md` の `## JSON Schema`） |
| 性能 | 1 回の呼び出しの照合は、引数の木を 1 回たどるだけにする | フックの決定値（非機能要件）を超えない |
