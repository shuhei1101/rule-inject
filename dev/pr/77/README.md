# MCP の引数の条件の木のタグでルールを当て、使われていないタグのパターンを索引のチェックで警告する

## 概要

利用者が、dev-docs の `search_docs` の `filter`（条件の木）の中のタグ・文書の種類で索引のエントリを当てられ、索引のチェックで dev-docs のどのタグにも当たらなくなったタグのパターンに気付けるようになる。

## 背景

[Issue #71](https://github.com/shuhei1101/rule-inject/issues/71) の要望。
索引の `args` は MCP のツールの引数にドットの道筋（`filter.tags` など）で当てる（[#34](https://github.com/shuhei1101/rule-inject/pull/34)）。
dev-docs の `search_docs` の `filter` が `field`・`op`・`values` の条件と `and`・`or` の束の木になり、道筋では値に届かずタグでルールを当てられない。
タグのマスターを持たないと決め直した（話し合いの D-169）ため、索引に書いたタグのパターンが使われているどのタグにも当たらなくなっても気付けない。
警告は、[#64](https://github.com/shuhei1101/rule-inject/issues/64) の `paths` の当たらないエントリの検出と同じ `check_indexes` に置く。
