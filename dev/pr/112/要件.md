# 要件

## 要望

セッションの開始時に、SessionStart のフックが常駐の MCP サーバーの応答を確認し、応答しないときは systemd --user のユニットでサーバーを起動する。

- 確認する先は `127.0.0.1` の `RULE_INJECT_PORT`（無ければ既定のポート `8783`）で、サーバーの待ち受けと同じ値にする
- サーバーが応答するときは、何も起動しない
- 起動はユニットへの依頼だけにし、サーバーの待ち受けの開始を待たない。フックは非機能要件「フックの実行時間」（1 秒）の内で終わる
- ユニットが無い端末・`systemctl --user` を使用できない端末では、何も起動せずに終える
- どの経路でも終了コード 0 で終え、セッションの開始を止めない。起動を依頼できなかったときは、ER 図「ログ」のログへ記載する
- 起動を依頼したセッションには、サーバーが待ち受けを始めた後に `/mcp` で接続し直す旨を `additionalContext` で案内する。起動を依頼したセッションは最初の接続に間に合わないため（PoC 検証）、同じセッションでの接続は、この接続し直しで行う。次に開くセッションは最初から接続できる
- サーバーの起動と管理は今までどおり systemd --user が主で、フックはその補助にする（規約『MCP サーバー作成ルール』の `sdk-transport-06`・規約『ローカルサーバーの立て方』の `resident-01`）

`未確定`: 起動するユニットの条件（決める段: インターフェース定義設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | ユニットが有効（`systemctl --user is-enabled`）なときだけ起動する | 利用者が `disable` で常駐をやめたサーバーを起動し直さない | 有効にせずに配置したユニットは補助されない |
| B | ユニットがあれば、有効かによらず起動する | 配置しただけのユニットも補助される | 利用者が意図して止めたサーバーを、次のセッションの開始で起動し直す |

推奨: A

`global-setup` は `enable --now` で有効にするため、有効でないユニットは利用者が常駐をやめた状態と判断できる。

`未確定`: フックがユニットのサービス名を知る方法（決める段: インターフェース定義設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 設定ファイルに `global` のキーを追加し（既定 `rule-inject`）、`global-setup` が `--service` の値を記載する | フックが既に参照する設定ファイルで完結し、別名のサービスも補助できる | 設定ファイルのキーと `global-setup` の手順が増える |
| B | 既定の `rule-inject` に固定する | 設定ファイルもスキルも変えない | `--service` で別名にした端末は補助されない |
| C | 環境変数（`RULE_INJECT_SERVICE`）で受ける | 設定ファイルを変えない | `env` への記載が増え、変えたら Claude Code の起動し直しが要る |

推奨: A

`global-setup` は `--service` で別名を受け付けており、設定ファイルはフックが毎回参照する置き場所のため。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| ユニットの無い端末で、フックがサーバーを直接起動する | 規約『ローカルサーバーの立て方』の `forbidden-01` が、tmux・systemd の外での常駐を禁じている | 予定なし |
| セッションの途中で落ちたサーバーの起動 | 規約が補助を SessionStart のフックに定めており、途中で落ちたサーバーは systemd の `Restart=on-failure` が起動し直す | 予定なし |
| `.mcp.json` への `alwaysLoad` の付与 | 規約『MCP サーバー作成ルール』の `sdk-transport-05` は、毎ターン使用するツールを持つサーバーだけに付けると定めている。PoC 検証で、付与しても起動を依頼したセッションの接続は変わらなかった | 予定なし |
| サーバーの起動を速めて、起動を依頼したセッションの最初の接続に間に合わせる | 要件の見直しで、`/mcp` の接続し直しの案内で足りる案に決めた（[確認ログ](./確認ログ.md)） | 予定なし |
