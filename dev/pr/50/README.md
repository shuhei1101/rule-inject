# Bash の for の語の並びと glob で読んだファイルにルールを案内する

## 概要

Bash の `for` の語の並びと、読むコマンドの引数の引用符の外の glob で読んだファイルにも、当たるルールを案内し、全体を読んだときは既読にする。

## 背景

[Issue #49](https://github.com/shuhei1101/rule-inject/issues/49) の不具合。
`for f in src/tasks/*.py tests/unit/tasks/test_service.py; do echo "=== $f"; cat "$f"; done` で読んだファイルに当たるルールの案内が出ず、ai-monitor の E2E（[shuhei1101/ai-monitor#3032](https://github.com/shuhei1101/ai-monitor/issues/3032)）でケースが落ちた。
`extract_read_paths` は、区切った各コマンドの先頭が読むコマンドのときだけ実在するファイルの引数を拾うため、glob の引数も、`for` の語の並びも拾わない。
ルール案内と既読の記録（[#47](https://github.com/shuhei1101/rule-inject/pull/47) でマージ済み）の両方が同じ関数を呼ぶ。
