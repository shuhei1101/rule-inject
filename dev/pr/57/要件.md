# 要件

## 要望

- 索引のエントリに、注入の有効・無効を切り替えるキー `enabled` を追加する
  - 値は `true` / `false`。省くと `true` で、キーを書かない今の索引は今と同じに動く
  - `true` / `false` 以外の値は、今の許さない値と同じく、その索引を読めなくする（索引の場所と理由がコンテキストに載る）
- `enabled: false` のエントリは照合に使わない
  - 当たるファイル・MCP のツールを操作しても、止める案内も止めない案内も出さない（ルール案内・検索結果の案内）
  - そのエントリの `read_by` と、そのエントリのルールを Read・Bash で読んだときは既読にしない
  - 同じルールの場所を指す有効なエントリが別にあれば、そのエントリで今までどおり照合する
