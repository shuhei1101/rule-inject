# 索引のエントリごとに、注入の有効・無効を切り替えるキーを持たせる

## 概要

利用者が、索引のエントリを消さずに、そのルールの注入と案内を止められるようになる。

## 背景

[Issue #56](https://github.com/shuhei1101/rule-inject/issues/56) の要望。
今はルールの注入を止めるには索引からエントリを消すしかなく、`default_on`・`on` は未読のときに操作を止めるかの設定で、注入そのものは止めない。
knowledge では React への移行に伴い Next.js の規約（`dev/コーディング規約/next/`）を当面使わないと決め、文書を残したまま注入だけを止めたい（knowledge の話し合いの D-1）。
