# MCPサーバー

常駐の MCP サーバーの起動とツールの入出力と処理フロー

## 目次

<!-- table: data -->

| ページ | 概要 |
| --- | --- |
| [サーバーの起動.py](./サーバーの起動.py.yaml) | 設定ファイルのポートで 127.0.0.1 に待ち受け、SIGTERM で止まる |
| [ルールの一覧.py](./ルールの一覧.py.yaml) | プロジェクトで効いている索引とエントリを返す（list_rules） |
| [ルールの検索.py](./ルールの検索.py.yaml) | パスか MCP のツールの呼び出しに当たるルールと止めるかを返す（search_rules） |
| [索引のチェック.py](./索引のチェック.py.yaml) | 索引ごとにフックが読めない理由・Schema の違反・無いルールのファイル・paths の当たらないエントリを返す（check_indexes） |
| [エントリの書き込み.py](./エントリの書き込み.py.yaml) | 索引のエントリを新規作成・編集し、チェックに通るときだけ書き込む（write_index_entry） |
| [エントリの削除.py](./エントリの削除.py.yaml) | 索引のエントリを削除し、チェックに通るときだけ書き込む（delete_index_entry） |
| [既読の記録の確認.py](./既読の記録の確認.py.yaml) | セッションの既読のルールと読んだ方法、または既読の記録のあるセッションの一覧を返す（get_read_records） |
| [既読の記録の削除.py](./既読の記録の削除.py.yaml) | セッションの既読の記録と案内済みの記録を削除し、ルールを未読に戻す（delete_read_records） |
| [サーバーの状態の確認.py](./サーバーの状態の確認.py.yaml) | 待ち受けのポート・プロセス・バージョン・クローンの commit・設定ファイルを読めるかを返す（get_server_status） |
| [設定の再読込.py](./設定の再読込.py.yaml) | 設定ファイルを読み直し、読めたかと読んだ値を返す（reload_settings） |
| [サーバーの再起動.py](./サーバーの再起動.py.yaml) | 処理中の呼び出しの終わりを待って待ち受けを閉じ、同じプロセスで起動し直す（restart_server） |
| [サーバーの更新.py](./サーバーの更新.py.yaml) | クローンへ上流の commit を取り込み、依存を入れ直して再起動する（update_server） |
