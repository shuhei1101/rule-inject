# プラグイン

フックと MCP のツールの入出力と処理フロー

## 目次

| ページ | 概要 |
| --- | --- |
| [ルール案内.py](./ルール案内.py.yaml) | 操作の対象に当たる未読のルールを、止めて、または止めずに案内する（PreToolUse） |
| [セッションIDの付与.py](./セッションIDの付与.py.yaml) | この MCP のツールの引数へ session_id を足す（PreToolUse） |
| [ルール本文の取得.py](./ルール本文の取得.py.yaml) | ルールの場所か対象のパスから本文を返し、既読として記録する（MCP のツール read_rules） |
| [既読の記録.py](./既読の記録.py.yaml) | Read か Bash で読んだルールの場所を既読として記録する（PostToolUse） |
| [既読の記録の破棄.py](./既読の記録の破棄.py.yaml) | 圧縮の前にそのセッションの既読の記録を消す（PreCompact） |
| [作業の決まりの注入.py](./作業の決まりの注入.py.yaml) | 新しいファイルは空で作ってから書く決まりを載せる（SessionStart） |
| [既読の記録の掃除.py](./既読の記録の掃除.py.yaml) | セッションの開始時に、保持期間を過ぎた既読の記録を消す（SessionStart） |
